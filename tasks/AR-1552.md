# AR-1552

Add the canonical plan materialization service needed by a plan-creation
command. It must enumerate the currently supported runnable workloads from the
same registry/catalog used by validation, allow a user to select one or more
workloads, and produce a schema-valid content-addressed experiment plan. New
workloads must become selectable by registry addition rather than a second
hard-coded CLI list. Preserve workload identity, scorer revision, measurement
selection, agent/provider neutrality, and fail-closed validation. Do not add
live credential handling or bypass runtime authority.
