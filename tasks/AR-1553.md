# AR-1553

Expose a first-class `asb plan-create` workflow backed by AR-1552. It must be
usable interactively and in scripts, show all currently supported workloads,
permit explicit workload selection, write a plan to a requested path, and
validate the result before writing it. The command must have clear errors,
stable machine-readable mode, safe defaults, and no secret or live-provider
side effects.
