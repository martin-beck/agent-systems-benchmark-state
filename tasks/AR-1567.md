Remove the host-specific `/usr/bin/cargo` assumption from the development
materializer. Resolve cargo, git, and process-control tools through a bounded,
explicit toolchain policy and a development-only override suitable for user
toolchains and CI. Preserve stable behavior, prevent arbitrary PATH execution,
and return typed diagnostics when no trusted toolchain is available. The
prototype must not require authentication, signatures, or key management.
