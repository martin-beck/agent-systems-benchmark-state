This is an ASB test-runner repair. It must not weaken production sandboxing or
permit a host-network fallback. The runner may use direct `unshare --net`, an
explicit `systemd-run --user` unit with `PrivateNetwork=yes`, or bubblewrap
`--unshare-net` only after a bounded capability and loopback-only preflight.
The selected backend, probe result, cleanup result, and exact tool identity
must be recorded in the machine-readable receipt. Development credentials,
signatures, and key management remain unrelated warning-only concerns.

- The backend must be selected from a closed enum; no shell string or arbitrary
  user-provided command may be executed.
- Every case must run with no external network route, retain loopback for
  local fixtures, enforce bounded output/time/workspace, and reap descendants.
- If no backend is available, return typed `runner_unavailable`; never execute
  the case on the host network and never report a pass.
- Existing direct-unshare behavior and all fault classifications must remain
  compatible unless the receipt explicitly records the selected backend.
