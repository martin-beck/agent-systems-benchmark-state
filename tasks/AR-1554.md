# AR-1554

Define and implement a global output contract for ASB commands: concise,
human-readable output by default, with the existing structured JSON output
available through a global `--json` flag. Preserve stdout/stderr boundaries,
exit codes, sensitive-data redaction, stable error codes, and script
compatibility where explicitly documented. Cover doctor, catalog, setup,
planning, run/report/compare, recording, replay, and provider commands rather
than fixing only one command.
