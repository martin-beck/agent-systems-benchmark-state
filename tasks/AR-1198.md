Define one renderer-neutral, cross-repository digest identity for the ASB v1.4
`AgentCatalog`. The digest must exclude only its own `catalog_sha256` member,
canonicalize JSON object-key order deterministically, preserve and validate
protocol-defined array order, and use lowercase SHA-256 over the exact compact
UTF-8 JSON bytes. A frontend must be able to recompute the identity without
linking ASB internals or reading private state.

Acceptance criteria:

- the canonicalization algorithm, hash scope, escaping/number rules, ordering
  invariants, malformed behavior, and cross-repository test vectors are documented;
- ASB validates the advertised digest against the complete typed snapshot and
  fails closed on mismatches, duplicate/unsorted IDs or capabilities, unknown
  fields, invalid identities and target drift;
- checked-in positive and negative fixtures plus Rust tests prove member-order
  independence, self-field exclusion, array-order sensitivity, and malformed
  input rejection;
- implementation remains confined to ASB control protocol/schema/tests/docs;
  no renderer, TUI, Ratatui, Crossterm or application code is added;
- PR #174 exact-head CI, independent review, signed DCO/SSH commits, protected
  merge and post-merge assurance are recorded before completion.
