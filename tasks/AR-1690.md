The omitted channel resolves to `dev`. In the development channel the resolver
must select the latest repository `main` head for ASB and the paired TUI source,
write a versioned manifest containing exact heads and digests, and expose the
same result through human-readable and `--json` output. Missing credentials,
generated signatures, and key-management metadata are development-only warnings
and must never block materialization. Stable, nightly, and experimental remain
named extension points with typed unavailable-channel diagnostics.
