# AR-1544

The approved coordinator v0.3.50 snapshot no longer exposes the state
repository's own linked worktrees in `project_scan`, while ASB's coordination
contract and tests require those worktrees to be visible for ownership,
dirty-tree and exact-head safety checks. This is a real compatibility gap, not
a reason to delete or weaken the test.

Audit the v0.3.50 implementation and the ASB contract. Repair the smallest
approved layer: prefer a coordinator-source successor and immutable vendored
release; an ASB adapter is acceptable only if it does not modify vendored
coordinator files or hide state worktrees. Preserve bounded observations,
privacy, exact-head identity, and fail-closed dirty/overlap detection.

Acceptance requires positive and negative worktree-scan tests (product and
state repositories, detached and dirty worktrees, missing or malformed
metadata), focused and full state gates, vendor/provenance verification,
Ruff/format/mypy/privacy checks, independent review, signed+DCO history and
green exact-head CI. Do not accept a test-only expectation change that loses
state-repository safety coverage.
