This ASB-side repair is test infrastructure only. It must not weaken production
sandboxing or permit a host-network fallback. The runner may use direct
`unshare --net`, an explicit `systemd-run --user` unit with `PrivateNetwork=yes`,
or bubblewrap `--unshare-net` only after a bounded capability and loopback-only
preflight. The selected backend, probe result, cleanup result, and exact tool
identity must be recorded in the machine-readable receipt.

- Backend selection is a closed enum; arbitrary shell strings are forbidden.
- Each case has no external route, retains loopback for local fixtures, and
  preserves bounded output/time/workspace and descendant cleanup.
- No backend means typed `runner_unavailable`; never execute on the host network
  and never report a pass.
- Existing classifications remain compatible, with the selected backend added
  to redacted evidence.
