## AR-1523

Qualify the existing central orchestration path for development and
first-customer-style local execution using deterministic local/mock and
strict-replay authority. A non-test deployment adapter may be implemented in a
separate future production-hardening AR; it is not a prerequisite for this
development qualification.

- Exercise the central orchestrator through the existing local/mock owner and
  strict-replay owner, including bounded run/sweep scheduling, cancellation,
  teardown, expiry, revocation and alternate-egress denial.
- Keep authority construction private to the runtime/control owner; no CLI
  option, config, environment variable, PATH lookup, fixed host path, public
  catalog, or digest-only record may construct it.
- Use deterministic local/mock/replay tests for development and CI. External
  provider reachability and deployment-owned authentication are optional
  supplementary production evidence only.
- Add or retain negative tests for missing, stale, expired, revoked, restarted,
  mismatched, replayed and tampered authority, plus cleanup and unknown-field
  rejection. Run exact-head review, signed+DCO gates and hosted CI.

This AR is the development qualification boundary. It does not weaken formal
AR-1307/1308 gates, privacy contracts or release qualification. A future
production-live adapter may build on this evidence but is optional and separate.
