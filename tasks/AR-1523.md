## AR-1523

Implement the missing non-test platform adapter identified by AR-1508 and
AR-1510. It is the owner of the private runtime authority required for first-
customer ASB workloads; it must feed only an opaque source into the existing
runtime/control bridge.

- Obtain lease/relay roots, namespace identity, pinned tools, egress policy and
  allowlist, credential capability and enrollment material from authenticated
  runtime/platform state. Bind every value to the AR-1505 receipt, generation,
  restart, cancellation, expiry and revocation fences.
- Keep private material inside the runtime/control owner. No CLI option,
  config, environment variable, PATH lookup, fixed host path, public catalog,
  or digest-only record may construct authority.
- Wire the opaque one-shot dispatch source into ordinary ASB run/sweep and
  scheduler transitions, including cancellation, teardown and alternate-egress
  denial. Do not modify asb-tui or require a live external provider in CI.
- Use deterministic local/mock/replay provider tests for development and CI;
  external provider reachability is optional supplementary evidence only.
- Add negative tests for missing, stale, expired, revoked, restarted,
  mismatched, replayed and tampered platform state, plus cleanup and unknown
  field rejection. Run exact-head review, signed+DCO gates, hosted CI and
  post-merge first-customer deployment verification.

This AR is the production handoff boundary. It does not weaken existing
development mocks, formal gates, privacy contracts or release qualification.
