Implement the dev channel's bounded source acquisition and build path. Resolve
the current `main` commit before cloning, clone into a private temporary
workspace, build with the locked toolchain, verify the resulting executable
digest and source identity, then atomically stage only the required executable
and development metadata. Enforce quotas, timeouts, owner-only permissions,
cleanup, and no credential/environment leakage. A failed build or cleanup must
leave the prior installation untouched.

This path is development-only and must not weaken the signed stable channel.
