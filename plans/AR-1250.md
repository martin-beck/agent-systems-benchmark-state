# AR-1250: Extend MockAgents qualification harness

## Outcome

Extend the ASB MockAgents qualification harness to exercise the pinned executable on an explicit
platform/runner selection and cover the hostile lifecycle and isolation cases missing from AR-1249.

## Dependencies and ownership

Dependencies: AR-0888, AR-0889. AR-1249 supplies the immutable amd64/arm64 artifact evidence.
Own only ASB MockAgents qualification harness, fixtures, and its runner contract; do not modify
asb-tui or weaken existing gates.

## Acceptance

- Select amd64 or arm64 only from an explicit pinned runner/platform contract, never host inference.
- Run the real pinned executable under emulated AArch64 and native supported execution where available.
- Add bounded positive/negative coverage for hostile tool/tool-result data, cancellation and
  backpressure, outbound-network denial, repeated clean-state runs, malformed input, and cleanup.
- Publish sanitized evidence with exact artifact digests; run focused/full locked gates, independent
  review, signed-DCO exact-head CI, protected merge, post-merge verification, and release only green.
