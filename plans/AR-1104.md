# AR-1104: Integrate --use-config into plan, run and sweep

## Outcome

`plan`, `run` and `sweep` accept `--use-config <config.toml>` and resolve the per-agent effective
provider/model from a UserConfigV1 file, feeding the existing digest-pinned provider-selection
path so the downstream `validate_provider_selection` and run-time profile negotiation stay
unchanged and fail closed.

## Dependencies and ownership

Dependencies: AR-0876, AR-1101, AR-1102 and AR-1103. Repository:
`martin-beck/agent-systems-benchmark` only. Owned paths are the `plan`, `run` and `sweep` option
handling and selection resolution in `crates/asb-cli/src/lib.rs` and tests. It reuses AR-1101's
registry-driven resolution and AR-1102's UserConfigV1 and does not add new provider-specific
branches. When all agents share one provider the resolution emits a `ProviderPlanOutput`-shaped
selection and reuses the existing digest check; per-agent overrides resolve each agent through the
registry-driven translation before preflight. No live API, network or credential value is
required. Branch: `feature/use-config`. Worktree: `agent-systems-benchmark-use-config`.

## Work sequence

1. Accept `--use-config <path>` on `plan`, `run` and `sweep`, alongside the existing
   `--provider-selection` flag, and reject the two together as ambiguous.
2. Load and validate the UserConfigV1 file (AR-1102 validation, AR-1103 reader bounds). Resolve the
   effective provider and model for each selected agent: `defaults` apply to all, and any matching
   `agents.<id>` override replaces them (single override scope per AR-1102).
3. Resolve every agent through AR-1101's registry-driven translation; if any agent's route or
   credential source is unsupported, fail closed before any external effect with a bounded
   preflight-style report.
4. When every selected agent resolves to one provider, build a `ProviderPlanOutput` with the
   canonical `catalog_sha256` and `selection_sha256`, then continue through the existing
   digest-pinned `plan`/`execute_with_selection` path unchanged.
5. Test default-only, per-agent override, mixed unsupported routes, stale catalog digest, missing
   config file, oversized config, and secret-shaped content all fail closed with bounded errors;
   prove the selection output is byte-identical to the equivalent explicit `--provider-selection`
   invocation.

## Acceptance criteria

A config file alone drives plan/run/sweep with no additional flags beyond `--use-config`, all
outputs are byte-identical to the explicit selection path, every failure mode is bounded and
credential-free, and nothing writes back to the config file.

## Evidence

Record byte-identical selection comparisons, per-agent override transcripts, fail-closed tests,
privacy scan and exact-head CI.
