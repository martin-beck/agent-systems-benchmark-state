# AR-0808: Publish core program workflow guides

## Outcome

Provide task-oriented, executable workflows for the main ASB program from installation through reproducible result analysis.

## Dependencies and ownership

Dependencies: AR-0314, AR-0401, AR-0505, AR-0801, AR-0802, AR-0821, AR-0822, AR-0872, AR-0873, AR-0874.
Owned paths: `docs/workflows/` core guides, examples, diagrams, command transcripts generated from public fixtures, and documentation tests.
Branch: `docs/core-workflow-guides`. Worktree: `agent-systems-benchmark-core-workflow-guides`.

## Work sequence

1. Document install/upgrade, doctor, agent/provider setup, shared OpenAI/Ollama profiles, workload selection, plan validation, single runs, sweeps, cancellation, recovery, replay/live selection, comparison, reports, and export.
2. Provide beginner paths and concise automation/reference variants with copyable commands and expected structural output.
3. Run every safe example against disposable public fixtures; label credentials, network, hardware, cost, and platform prerequisites before effects.
4. Add architecture and sequence diagrams for runner/store/adapter/replay boundaries and failure recovery.
5. Test links, commands, schemas, generated output, privacy, unsupported combinations, and version drift in CI.

## Acceptance criteria

Users can complete offline and opt-in live workflows without undocumented steps; examples never expose credentials, private paths, prompts/responses, or mutable unpinned inputs; commands match released binaries; replay cannot be mistaken for live evidence; destructive/cost-bearing effects are explicit; and support claims derive from the tested matrix.

## Evidence and completion

Record example run IDs/artifact digests from synthetic data, immutable commits, reviews, exact-head CI, link/schema checks, and versioned limitations.
