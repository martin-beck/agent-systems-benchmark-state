# AR-1446: First-customer production qualification

## Objective

Qualify ASB in a disposable environment matching the first-customer deployment contract. This is an integration and release gate, not a CI live-provider requirement. The mandatory execution dependency is the deterministic runtime mock; AR-1329's optional external-provider path is explicitly not a prerequisite.

## Boundaries

Hosted CI remains credential-free and network-denied. Provider/model/agent selection uses a fresh catalog and content-pinned plan. Optional live-provider smoke is operator-authorized, bounded, redacted, and separate from local qualification evidence.

## Required work

1. Define a disposable customer-like environment with pinned product, workload, provider/model/agent selection, credential reference, runner properties, and rollback/cleanup.
2. Verify clean install, bootstrap, reconfiguration, benchmark execution, result inspection, strict offline replay, cancellation/restart recovery, and removal without leaking credentials, prompts, responses, or private paths.
3. Run the complete built-in and released literature-workload matrix through the deterministic local mock path with bounded digest-only evidence.
4. If an operator supplies a provider key, run a separate catalog-pinned smoke recording only status, timing, token counters, and digests. Provider outage must not invalidate local qualification.
5. Independently review the exact tree, run all applicable gates, verify exact post-merge CI, and publish a readiness report with supported combinations, rollback steps, and unresolved optional live gaps.

## Acceptance

The disposable customer-like environment completes the documented install, configuration, local benchmark, replay, recovery, and cleanup journey on a clean exact release candidate. Evidence is reproducible and privacy-safe, required gates are green, and the report distinguishes local qualification from optional remote reachability.
