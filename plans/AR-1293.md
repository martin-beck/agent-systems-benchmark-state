by AR-1181. The work is strictly in the ASB state repository: bind formal
admission to a real state worktree, implement the missing bounded TLC runner
around the existing admission boundary, and preserve the product repository's

existing `formal/handoffctl/verify.sh` callers and implement only the missing

  input, and provenance-negative tests pass offline with bounded evidence.

  post-merge verification pass; otherwise record a precise blocker and release
