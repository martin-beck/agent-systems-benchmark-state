# AR-1314: Optional runtime-bundle signing for development and tagged releases

## Scope

Change the ASB runtime-bundle contract and release/install tooling so an explicit
`unsigned-development`/`unsigned-release` profile can publish and consume a bundle without
`manifest.json.sig`. Keep the default profile signature-required. Preserve exact inventory,
content digest, SBOM hashes, licenses, target identity, provenance, and immutable tag/commit
checks. Record `signature_status: unsigned` in bounded public metadata and make every formal,
qualification, and default-install path reject that status.

## Acceptance

- Versioned schema and docs define the explicit profile and reject unknown fields.
- Positive tests cover unsigned development and explicitly selected tagged-release publication.
- Negative tests cover silent/default unsigned use, missing digests/SBOM/provenance, profile drift,
  and formal/full-attestation attempts using unsigned inputs.
- Bootstrap/install behavior is bounded, offline after acquisition, and emits actionable errors.
- Focused and full applicable gates, privacy/provenance checks, SSH-signed DCO commit review,
  exact-head CI, and post-merge verification pass.
