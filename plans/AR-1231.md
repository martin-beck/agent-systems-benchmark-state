# AR-1231: Strict replay execution and egress-isolation seam

## Outcome

Provide the adapter-facing run-path contract that executes a real agent against a pinned
`StrictReplayService` route with provider egress denied at the process boundary. Replay must be
fail-closed across launch, mismatch, cancellation, restart, timeout, crash recovery, and partial
launch; it must never silently fall back to a live provider.

## Dependencies and ownership

Dependencies: AR-0505, AR-1100, AR-1230. Repository: `martin-beck/agent-systems-benchmark`.
Owned paths: the versioned replay launch contract and adapter/run-path integration under
`crates/asb-agents` and shared replay/runtime seams, plus focused tests and public docs/schema.
Do not modify `asb-tui` or own AR-1151 campaign/default integration.

## Acceptance

- Define a versioned typed launch record binding exact cassette digest, replay service/route,
  provider dialect, agent/adapter, run and attempt identity, workload, and bounded process policy.
- Pass only the approved local replay route/service to the adapter; reject provider endpoints,
  credentials, ambient configuration, live-fallback attempts, mismatched route/cassette/agent/
  attempt identities, stale generations, malformed records, and unsupported adapters.
- Enforce process-level provider egress denial for the adapter and descendants, independent of
  adapter cooperation, with bounded startup, timeout, cancellation, restart, and shutdown.
- Prove denial and fail-closed behavior on startup failure, unmatched request, timeout,
  cancellation, retry, crash recovery, and partial launch; never reuse stale sockets/cursors.
- Keep credentials absent from argv, ordinary environment, config, control frames, logs, errors,
  caches, fixtures, and evidence.
- Add deterministic bounded loopback tests for successful real adapter replay, unmatched request,
  external-provider denial, child-process egress attempt, digest/route mismatch, stale generation,
  duplicate attempt, cancellation, restart, timeout, crash recovery, and report labeling.
- Update generated schemas and docs with the consumer handoff required by AR-1151.
- Run focused replay/adapter tests, locked workspace tests, fmt, Clippy warnings-denied, rustdoc/
  release build, privacy/supply-chain/formal applicable gates; use signed DCO commits and exact-
  head independent review/CI before merge and post-merge verification.

## Explicit non-goals

No provider discovery, credential storage, campaign matrix/default selection, TUI changes, live
network integration, or release publication.
