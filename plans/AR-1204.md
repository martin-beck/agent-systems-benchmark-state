# AR-1204: Integrate the record-live → replay-offline benchmark workflow

## Outcome

Deliver the complete user journey for the specific in-tree workloads:
`plan → live record (OpenRouter free model) → seal → offline replay run → report → compare`, with
campaign coverage and cost estimates for the free tier.

## Dependencies and ownership

Dependencies: AR-1201 (live capture), AR-1203 (replay-mode run/sweep), AR-0401 (workload suite).
Repository: `martin-beck/agent-systems-benchmark` only. Owned paths are
`docs/workflows/record-replay.md` (workflow), `record-campaign` + run/replay wiring in `asb-cli`,
`report`/`compare` replay labelling, workflow transcript fixtures, and README/PLAN command list
(text only; rendering updates land in AR-1206). Branch: `feature/record-replay-workflow`. Worktree:
`agent-systems-benchmark-record-replay-workflow`.

## Work sequence

1. Define the default matrix: workload subset (bug-fix, feature-addition, build-repair,
   refactoring) times selected agents, one OpenRouter free-model profile.
2. Execute the journey per tuple: live `run` with capture → seal cassette → replay-mode `run` →
   `report` both → `compare` with explicit `comparable` rules (redaction, truncation, profile
   identity, pacing are hard boundaries, not deltas).
3. Wire `record-campaign` against the matrix with per-tuple cost estimate and duplicate fencing;
   record free-tier cost observations (rate limits, availability) as evidence limits.
4. Add the full journey to the executable guide contract (`docs/examples/...` transcripts) so it is
   reproducible without a paid key via the deterministic double (AR-1207).
5. Publish bounded evidence: run IDs, cassette digests, redaction reports, no prompts.

## Acceptance criteria

Every tuple in the default matrix has a recorded cassette and a matching offline replay run; live
and replay results compare under the documented rules; campaign coverage is complete or explicitly
incomplete; no paid call is repeated for a finished tuple; cost/network acknowledgements are
mandatory.

## Evidence

End-to-end transcripts, campaign metadata, compare/report outputs, workload fixtures, signed DCO
commits, exact-head CI.
