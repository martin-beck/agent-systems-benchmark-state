# AR-1230: Authenticated provider-request seam and secret injection contract

## Outcome

Specify one approved, provider-neutral authenticated-request interface that accepts an opaque
resolved credential only at the transport boundary. The interface binds provider, endpoint
identity, enrollment generation and one bounded deadline while preventing credential disclosure or
ambient authority.

## Dependencies and ownership

Dependencies: AR-0319, AR-0320, AR-1100. Repository: `martin-beck/agent-systems-benchmark`.
Owned paths: provider protocol/auth seam, transport-facing credential injection contract,
provider-specific auth policy descriptors, and unit/negative/privacy/fault tests. AR-1228 consumes
this contract for bounded transport; AR-1229 consumes its public metadata and application seams.

## Acceptance

- Define a typed request with deny-by-default provider auth policy, endpoint digest binding,
  nonzero generation, one absolute bounded deadline, response cap and cancellation semantics.
- Permit only explicitly qualified auth placements at the final write boundary; reject credentials
  in argv, persistent config, ordinary environment, control frames, logs, errors, evidence and
  public state. Erase buffers on success and failure.
- Specify OpenAI-compatible, Gemini and Ollama auth placement policy, including unsupported modes.
- Make stale-generation, endpoint mismatch, cancellation and partial-write outcomes fail closed
  with no false success or durable mutation; transport timeout/redirect/response parsing belongs
  to AR-1228.
- Add positive, malformed, unknown-field, invalid-combination, privacy, cancellation, rotation/
  race and sink-failure tests using bounded loopback fixtures only.
- Update this seam's public schema/docs and record the exact handoff for AR-1228 and AR-1229. Run
  focused/full Rust quality and privacy/fault gates with signed DCO.

## Explicit non-goals

No ambient environment credential lookup, plaintext secret file, executable plugin, unpinned network
endpoint, provider network integration, CLI command, durable registry, release or merge.
