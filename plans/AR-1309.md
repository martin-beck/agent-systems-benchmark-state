# AR-1309: reviewed full-exhaustive capacity or model-reduction contract

## Objective

Resolve the terminal AR-1308 capacity failure without changing AR-1307's reviewed
3G memory, 3G swap, two-worker, two-core, 8G address-space, or 7200-second
admission contract. Produce either a separately reviewed disposable capacity
contract that can complete the exact liveness workload or an explicitly reviewed
model-reduction contract whose claims are distinct from full qualification.

## Dependencies and boundaries

- Depends on AR-1307 and the blocked terminal evidence from AR-1308.
- Preserve the existing signed source, pinned JDK/TLC/model inputs, admission
  lock, offline/no-host-mount isolation, and fail-closed attestation gates.
- Do not widen AR-1307's process limits, weaken formal gates, modify handoffctl,
  touch asb-tui, or reinterpret an OOM as a model result.

## Required work

1. Select and review one path: separately provisioned disposable x86_64
   capacity with measured guest/host memory, swap, disk, cgroup and cleanup
   evidence, or a deterministic model reduction with a new profile and claims.
2. Bind exact source, model/config, JDK/TLC and runner digests; require offline
   execution, no host mounts, bounded runtime, admission fencing and bounded
   sanitized diagnostics.
3. Add positive and negative tests for capacity insufficiency, Java OOM,
   timeout, disk exhaustion, wrong digest, stale lease, concurrent admission,
   cleanup failure, and model/profile mismatch. Fail closed in every negative
   case.
4. Run focused/full gates, independent review, exact-head CI and one terminal
   qualification attempt only after the contract is reviewed. Publish an
   attestation only when all evidence validates; otherwise record a classified
   blocker and leave AR-1307 unqualified.

## Acceptance gates

- Contract and profile are explicit, reproducible, signed and privacy-safe.
- Existing AR-1307 3G/3G/2-worker/7200 admission limits remain unchanged.
- Full-exhaustive success requires a valid liveness attestation; OOM, timeout,
  missing evidence and model-reduction results cannot qualify AR-1307.
- All commits are SSH-signed with matching DCO; product/state tests, formal,
  privacy, exact-head CI, review, merge and post-merge checks are green.
