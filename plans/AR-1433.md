# AR-1433: Runtime mock-attempt backend

## Objective

Provide a runtime-owned deterministic mock attempt for `asb run` and `asb
sweep`, enabling first-customer-like local qualification without external
provider access or fabricated live authority.

## Required work

1. Define a mock-only attempt/backend type separate from `LiveProviderAttempt`.
2. Bind it through the normal runtime scheduler and CLI run/sweep paths behind
   an explicit local-mock profile; reject accidental live or mixed selection.
3. Preserve bounded prompts/responses, credential non-disclosure, digest-only
   evidence, cancellation, timeout, restart, cleanup, and `NetworkPolicy::Deny`.
4. Add positive and hostile negative tests for wrong mode, loopback misuse,
   stale model/agent selection, oversized data, cancellation, and fallback.
5. Run focused and full offline gates, then publish through exact-head review
   and post-merge verification. Do not change AR-1432's optional production
   relay/egress blocker.

## Acceptance

An explicit local-mock `asb run` and `asb sweep` completes deterministic
fixture workloads through the ordinary dispatch path with no provider socket,
credential, or live authority. Repeated runs are bounded and reproducible;
negative cases fail closed; exact CI and post-merge gates are green.
