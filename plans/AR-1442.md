# AR-1442 — Guided setup wizard orchestration

## Scope

Turn the existing catalog, authentication, and configuration primitives into a
single ASB CLI guided setup flow. Present selectable agents, providers,
authentication methods, and only models supported by the selected provider;
allow one choice to apply to all or selected agents; validate connectivity
through the approved credential-helper/runtime path; persist safe defaults; and
make reconfiguration and provider addition the same flow as first-run setup.
Standalone asb-tui consumption remains a separate downstream integration.

## Dependencies

Depends on AR-1441, AR-1316, AR-1328, and AR-1436. Existing provider catalogs,
credential handoff, and local guided wrapper remain authoritative.

## Acceptance

- A first-run user can complete setup using selections and explicit typed
  secret-helper actions only; raw API keys never enter public protocol/state.
- The same wizard supports edit, add-provider, per-agent override, and
  apply-to-all/default operations with generation and stale-selection fencing.
- Missing credentials, unavailable models, failed probes, and cancellation
  produce actionable choices and never leave a half-applied configuration.
- The CLI emits the versioned setup contract and catalog digest without
  duplicating provider/model registries; downstream TUI wiring can consume it
  without changing this AR.

## Required evidence

Credential-free deterministic tests, hostile secret/path tests, local mock
provider qualification, and exact-head hosted gates. Cross-repository TUI wire
compatibility remains outside this ASB-only AR.
