# AR-1310 implementation plan

## Outcome

Qualify a real ASB recording campaign from provider-bound runtime capture through
restart-safe cassette coverage and verified strict offline activation.

## Owned paths

ASB product only: `crates/asb-cli/src/control.rs`, `crates/asb-control/`,
`crates/asb-replay/`, the runtime/provider launch integration in `crates/asb-runtime/`
and `crates/asb-agents/`, generated schemas/docs and their tests. Do not touch
asb-tui or the state coordinator implementation.

## Design obligations

1. Freeze the existing v1.8 control contracts and add only additive, versioned
   fields/operations with `deny_unknown_fields`; update generated schemas and
   examples together.
2. Define one runtime-owned capture trait/callback whose inputs derive exclusively
   from an authenticated launch handoff. It must return bounded sanitized metadata
   and cassette bytes/digest, never secrets or raw provider content in control
   projections.
3. Use durable mutation intent and a bounded per-tuple coverage journal. Bind each
   tuple to provider profile, model, workload/scorer revision, campaign generation,
   attempt identity and cassette digest. Recovery marks uncertain work stale.
4. Verify every cassette through redaction, canonical encoding, digest and strict
   replay compatibility before marking complete. Offline activation must atomically
   bind the exact complete coverage set and reject any later identity drift.
5. Keep all process, socket, timeout and artifact operations bounded; no shell,
   downloads, telemetry, floating versions or credential persistence.

## Test matrix

- positive: authenticated runtime callback captures a buffered and streaming fixture;
  one tuple and a multi-tuple campaign complete; restart restores complete coverage;
  idempotent retry returns the committed result; strict offline replay succeeds;
  offline-default activates only after exact coverage;
- negative: forged frontend endpoint/credential, callback bypass, malformed request or
  response, redaction failure, cassette digest drift, duplicate/missing tuple, stale
  generation, interrupted capture, repeated uncertain attempt, provider fallback in
  offline mode, oversized frame/artifact, unknown schema field and path-based
  importer attempting to mark a live campaign complete;
- gates: focused package tests, full `cargo fmt --all -- --check`, locked clippy,
  workspace tests, rustdoc warnings, release build, generated schema freshness,
  privacy/provenance/DCO/signature checks, independent diff review, exact-head CI and
  all required post-merge workflows.

## Handoff evidence

Record the immutable source/main commit, branch/worktree identity, signed commits,
PR and exact-head check IDs, review result, merged SHA, post-merge workflow IDs,
coverage/cassette fixture digests and the final state transition through handoffctl.
