# AR-0809: Publish terminal frontend workflow guides

## Outcome

Provide accessible, task-oriented documentation for installing and using the separate `asb-tui` frontend.

## Dependencies and ownership

Dependencies: AR-0802, AR-0804, AR-0805, AR-0806, AR-0807.
Owned paths: frontend user guide, onboarding, navigation/reference, troubleshooting, diagrams, safe captures, and documentation tests.
Branch: `docs/frontend-workflow-guides`. Worktree: `agent-systems-benchmark-frontend-workflow-guides`.

## Work sequence

1. Document connecting to the runner, the settings wizard, shared/per-agent providers, matching recording versus live choice, validation, launch confirmation, and status views.
2. Cover reconnect, cancellation, recent history, repeat-with-drift review, compatible comparison, result analysis, exports, keyboard map, accessibility/plain mode, and troubleshooting.
3. Generate screenshots/text captures only from synthetic public fixtures and provide equivalent alt text and linear instructions.
4. Explain runner/frontend isolation, freshness indicators, failure states, permissions, sensitive artifacts, and unsupported terminals/platforms.
5. Replay core journeys in automated pseudo-terminal tests and fail CI on stale labels, broken links, missing alt text, or commands that diverge from the release.

## Acceptance criteria

A new user can finish every core TUI journey from the guide; all actions and confirmations match the shipped UI; every visual has useful text equivalence; no capture contains private data; runner independence is clear; and limitations/troubleshooting are evidence-backed.

## Evidence and completion

Record automated journey results, capture provenance, accessibility review, immutable commits, exact-head CI, native terminal coverage, and post-merge checks.
