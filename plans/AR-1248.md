# AR-1248: Define the strict-replay CLI consumer contract

## Outcome

Define and implement the bounded, versioned CLI/plan contract that resolves a declared cassette
artifact by digest and constructs the authenticated runtime `SidecarHandoff` needed by strict
offline replay, without ambient paths, provider access, or arbitrary commands.

## Dependencies and ownership

Dependencies: AR-1231, AR-1232. Own only ASB protocol/CLI plan schema, resolver, and contract tests;
do not weaken replay fail-closed validation or modify asb-tui.

## Acceptance

- Versioned plan fields specify cassette identity and an allowed, bounded artifact-resolution root;
  unknown fields, traversal, symlinks, digest/size mismatches, and ambient configuration fail closed.
- CLI constructs an authenticated `SidecarHandoff`/sandbox launch input from verified bytes and
  never accepts arbitrary provider URLs, shell commands, or host-network sharing.
- Positive and negative offline tests cover resolution, identity, malformed plans, egress denial,
  cancellation, cleanup, and no-fallback behavior.
- Generated schemas/docs are updated; focused and full locked gates, signatures/DCO, review, PR,
  exact-head CI, protected merge, and post-merge verification all pass.
