# AR-1269: Runtime-owned replay launch-bundle factory

## Outcome

Provide a runtime-owned, authenticated factory that creates the complete supervised replay launch
bundle required by `SandboxBackend::spawn_launch`, while keeping immutable transport identity
separate from authority and preventing CLI fabrication.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1268 remains blocked design evidence and its unmerged
branch is not an input. Owned paths: ASB runtime launch-bundle construction, attestation and lease
binding, sidecar/supervisor command pinning, CLI adapter integration, and lifecycle fixtures/tests.
Branch: `feature/ar-1269-runtime-replay-launch-factory`. Worktree:
`agent-systems-benchmark-ar-1269-runtime-launch-factory`.

## Work sequence

1. Define an opaque runtime-only factory API that validates namespace/sidecar/adapter content hashes,
   route identity, resource lease ownership, and bounded pinned command paths before issuing a bundle.
2. Ensure the CLI receives only the opaque bundle/context and cannot supply launch input, lease,
   commands, readiness, endpoints, or digests. Consume it exactly once.
3. Add runtime-backed credential-free child fixtures proving cassette request/response, provider and
   descendant egress denial, cancellation/restart, timeout/crash reaping, cleanup/no leaks, stale/
   duplicate rejection, and no live fallback.
4. Run focused repeats, full locked offline gates, policy/privacy/schema/signature/DCO, independent
   review, exact-head CI, signed merge, and post-merge assurance.

## Acceptance criteria

Only runtime-issued launch bundles can reach supervised replay. All authority and lifecycle failure
paths fail closed with bounded evidence; real request/response and cleanup behavior is demonstrated
through the actual CLI dispatch path without dependency cycles or fabricated metadata.
