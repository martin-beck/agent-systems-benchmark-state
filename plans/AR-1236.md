# AR-1236: Runtime-owned loopback sidecar capability

## Outcome

Provide a reviewed, runtime-owned in-namespace sidecar/relay that exposes only the authenticated
cassette service to a strict-replay child without host-network sharing or provider egress.

## Dependencies and ownership

Dependencies: AR-1100 and AR-1231. Repository: `martin-beck/agent-systems-benchmark`. Own only
asb-runtime namespace/sidecar lifecycle, relay forwarding, attestation, and focused native tests.

## Acceptance

- Private network namespace with child-visible loopback endpoint and per-launch Unix relay.
- Provide a versioned sidecar handoff descriptor containing launch generation, cassette route
  digest, private Unix socket, child loopback endpoint, deadline, and pinned sidecar/adapter command
  digests. The launcher must start the sidecar and adapter in the same namespace and attest listener
  readiness before releasing the adapter.
- Immutable/pinned helper or in-tree supervisor; no ambient privileged setup or global firewall rules.
- Authenticated route digest and generation fencing; bounded forwarding and complete teardown.
- Positive cassette request, provider/descendant denial, stale/duplicate, timeout/cancel/crash,
  restart, partial-launch, and unrelated-process isolation tests.
- Preserve `NetworkPolicy::Deny`; unavailable capability fails closed.
- Signed DCO, locked quality/privacy/policy/native gates, exact-head review and CI.
