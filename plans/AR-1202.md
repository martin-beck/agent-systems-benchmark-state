# AR-1202: Make `asb replay` end-to-end usable

## Outcome

Close the authority gap so `asb replay` (and the runtime path behind it) issues a
`ReplayLaunchAuthority`, launches the adapter against the loopback `StrictReplayService` with
provider network denied, and returns the documented JSON/exit contract.

## Dependencies and ownership

Dependencies: AR-0102 (process runtime), AR-0503 (strict replay), AR-0504 (replay pacing),
AR-0314 (source choice), AR-1201 (capture sidecar patterns). Repository:
`martin-beck/agent-systems-benchmark` only. Owned paths are the `asb replay` command in
`crates/asb-cli/src/lib.rs`, the runtime authority-issuance entry point (e.g. `asb replay`
self-hosting the runtime supervisor), reuse of the replay relay + `loopback_sidecar`, and
`docs/workflows/record-replay.md` CLI route. Branch: `feature/replay-authority-cli`. Worktree:
`agent-systems-benchmark-replay-authority`.

## Work sequence

1. Add a runtime-supervised entry that constructs the `ReplayLaunchFactory` binding (cassette
   digest, launch input, lease), spawns the sidecar, and hands the authority to the existing
   `replay` dispatch path.
2. Launch the adapter (pinned executable) with the loopback endpoint and the strict replay
   service; assert no outbound provider route exists in the child namespace.
3. Keep all existing fail-closed rules: exact cassette/profile/agent match, one-shot authority,
   exhausted cursor, no fallback.
4. Emit the existing `ReplayWorkflowOutput` (source, network: denied, fresh_model_quality: false,
   digests) and correct exit codes; update `capabilities`, help, completion.

## Acceptance criteria

`asb replay CASSETTE PROFILE_SHA256 AGENT` works as a user-facing command for at least one
supported agent with zero provider network; wrong profile/agent/cassette and exhausted cassettes
fail closed; the standalone entry without authority still fails safely (no regression in
`workflow_transcript.rs` expectations, or the transcript is intentionally updated in AR-1206).

## Evidence

End-to-end native loopback replay journeys per adapter, network-denial probes,
one-shot/duplicate/replay-negative tests, signed DCO commits, exact-head CI.
