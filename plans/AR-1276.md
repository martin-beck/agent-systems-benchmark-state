# AR-1276: Integrate runtime operation into primary replay command

## Outcome

Wire the primary argument-level strict-replay command to obtain and consume a runtime-issued
operation handle, executing supervised cassette traffic rather than stopping at metadata or an
adapter-only response.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239, AR-1275. Owned paths: primary ASB CLI replay dispatch,
runtime launch integration, cassette/lifecycle fixtures, and executable tests. Branch:
`feature/ar-1276-primary-replay-runtime`; worktree: `agent-systems-benchmark-ar-1276-primary-replay-runtime`.

## Acceptance

The real replay command fails closed without authenticated runtime context, forwards bounded
requests through the supervised runtime operation, and proves response parity, provider and
descendant egress denial, no live fallback, cancellation/restart, timeout/crash reaping, cleanup,
and malformed/stale/duplicate rejection. Run locked full gates, independent review, exact-head CI,
signed merge, and post-merge assurance. Do not reuse blocked feature branches or weaken gates.
