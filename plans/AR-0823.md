# AR-0823: Audit installation and first-run experience

## Outcome

Independently prove that advertised installation and lifecycle workflows are secure, accessible, repeatable, and genuinely simple on supported native systems.

## Dependencies and ownership

Dependencies: AR-0807, AR-0821, AR-0822, AR-1012 and AR-1026. Installation qualification must use
the final qualified standalone UI and exact product-side router rather than the historical bundled
frontend path.
Owned paths: disposable install matrix, supply-chain/fault/usability audit, remediation evidence, and release gate.
Branch: `audit/installation-experience`. Worktree: `agent-systems-benchmark-install-audit`.

## Work sequence

1. Run the exact public one-liner from clean unprivileged homes on every claimed distro/architecture/libc/shell/service-manager cell, including SSH, tmux, proxy, offline, low disk, read-only path, bad clock, interrupted download, and hostile pre-existing file cases.
2. Attack bootstrap, redirect, manifest/signature, archive traversal, symlink, PATH, environment, downgrade, key-rotation, race, permission, and command-injection boundaries.
3. Have independent first-time users complete install/configure/start/reconnect/update/rollback/uninstall from published docs; measure time, errors, recovery, keyboard/accessibility, and whether choices are understandable.
4. Verify no root is needed by default, no secret enters history/argv/logs/artifacts, services and sockets are owner-only, benchmark processes are not coupled to TUI lifetime, and partial failures leave no unsafe residue.
5. Rebuild and compare release artifacts, validate SBOM/provenance/license completeness, repeat post-install doctor and a synthetic public benchmark, and publish honest unsupported combinations.

## Acceptance criteria

The advertised one-line path succeeds from a clean supported system through initial TUI start; no critical/high finding remains; all payloads and transitions are authenticated; negative/fault cases fail closed and recover cleanly; install/upgrade/uninstall docs match exact behavior; and native evidence exists for every support claim.

## Evidence and completion

Record immutable public fixture images, exact commands/digests/refs, native logs reduced to privacy-safe assertions, usability findings/remediation, independent approvals, exact-head CI, release URLs, and post-release smoke checks.
