# AR-0896: Qualify the pinned MockAgents executable

## Outcome

Produce credential-free, fail-closed black-box evidence for exactly one deterministic
LLM-double candidate. AR-0890 remains blocked unless this AR proves the pinned
MockAgents executable satisfies the complete AR-0888/AR-0889 hostile contract.

## Work sequence

1. Implement a closed lock parser and downloader/cache verifier. Reject unknown
   fields, unsupported platforms, redirects outside the pinned GitHub release URL,
   wrong size/digest/member/type/mode/license/version, missing artifacts, and
   trailing or duplicate archive entries before execution.
2. Extract without traversal or symlink/hardlink/device entries into unique bounded
   state, launch unprivileged on an allocated loopback port, strip credentials and
   proxy variables, impose process/file/time/output bounds, and verify exact identity
   readiness before sending a case.
3. Drive OpenAI Chat and Responses plus Anthropic Messages in buffered and SSE forms,
   including multiline data, usage, finish reasons, tools/tool results, parallel
   sessions, repeated fingerprints, cancellation and backpressure.
4. Exercise 4xx/5xx, disconnect, truncation, invalid JSON, delay, mismatch/exhaustion,
   late/bad base URL, startup failure, stale state, DNS and outbound-provider denial.
   A skip, no-op, fallback, unexpected connect, leaked sentinel, or substituted server
   is a hard failure.
5. Terminate the full child tree and prove port/state cleanup after success, failure,
   cancellation and concurrent runs. Retain only bounded public hashes/case outcomes;
   never credentials, environment values, private paths, prompts, raw logs or hosts.
6. Repeat the complete suite with fresh state and require identical ordered case
   inventory and deterministic response hashes. Keep evidence class `synthetic` and
   leave all provider/live/replay support catalogs unchanged.

## Acceptance criteria

The exact pinned executable, not an in-process substitute, passes every applicable
hostile case; unsupported behavior is explicit and blocks selection. Provenance and
license checks fail before extraction/execution under every mutation. No provider DNS
or egress occurs, no credential reaches the child, identity/readiness cannot be
spoofed, concurrency/cancellation leave no child/port/state, and two clean runs match.
The test suite includes wrong/missing/stale/substituted artifacts, corrupt archives,
unsafe members, wrong version/license/identity, skipped server, leak sentinel,
non-loopback bind, unexpected outbound connection, timeout and teardown failures.
