# AR-1035: Build recent-runs, report and comparison workspaces

## Outcome

Turn the versioned ASB history/analysis contract into a complete standalone TUI workflow for finding
recent runs, checking reports and comparing compatible results.

## Dependencies and ownership

Dependencies: AR-0875, AR-1025 and AR-1033. Repository: `martin-beck/asb-tui` only. Owned paths are
history/report/compare screens, client projections, filters/search/sort state, selection actions,
snapshots and interaction tests. Any missing data field or query semantic belongs in a separate
ASB protocol AR; no ASB renderer or report UI is permitted.
Branch: `feature/tui-reports-compare`. Worktree:
`agent-systems-benchmark-asb-tui-reports-compare`.

## Work sequence

1. Show a bounded, paginated and searchable recent-runs list with freshness, time, status, agents,
   workload, provider/replay source, platform, integrity and concise result.
2. Open a report workspace with provenance, measures, uncertainty, failures, artifact availability
   and exact reproducible CLI commands; keep sensitive artifact contents behind explicit access.
3. Support keyboard multi-selection of runs and deliberate compare; display compatibility decision,
   confounders, excluded measures, uncertainty and numeric equivalents before any conclusion.
4. Preserve selection/filter/sort across resize, detail/back navigation and authoritative page
   refresh without retaining deleted/stale identities as valid.
5. Test empty/large/deleted/corrupt/legacy/incomplete histories, pagination races, incompatible runs,
   reconnect, export redaction and bounded rendering/resource use.

## Acceptance criteria

Recent runs are reachable from landing in one action; users can find a run, inspect its report and
compare selected compatible runs without memorized IDs; incompatible or incomplete evidence never
looks successful; and all displayed conclusions map to exact public ASB evidence.

## Evidence

Record protocol-fixture parity, exact history/report/compare snapshots, keyboard journeys,
compatibility negatives, pagination/fault/resource tests, privacy review, exact-head CI and
post-merge verification.
