# AR-0315: Verify cross-agent provider parity

## Outcome

Independently prove that all claimed agents receive identical effective provider settings and that replay/live selection preserves those identities.

## Dependencies and ownership

Dependencies: all agent adapters, AR-0311 through AR-0314, and AR-0505 as listed in task metadata.
Owned paths: provider-agent conformance harness, synthetic endpoints, parity fixtures, platform matrix, and public evidence.
Branch: `test/provider-parity-conformance`. Worktree: `agent-systems-benchmark-provider-parity-conformance`.

## Work sequence

1. Capture redacted effective requests at each real agent boundary for common OpenAI and Ollama profiles.
2. Compare normalized and wire-effective fields, tool schemas, streaming, retries, deadlines, and cancellation.
3. Exercise live choice, every compatible recording choice, no-match behavior, corruption, and network-denied replay.
4. Run parallel identical sessions to detect state leakage, hidden defaults, credential bleed, and nondeterministic profile translation.
5. Publish the exact supported/unsupported agent-provider-platform matrix and all evidence limits.

## Acceptance criteria

Every support claim has a real pinned-agent boundary test; identical means all requested and observable effective fields match, not merely that runs complete; unsupported or unobservable settings remain unsupported; replay and live cannot be confused; failures are fail-closed and privacy-safe; and native/platform limits are explicit.

## Evidence and completion

Record immutable commits, upstream pins/licenses, exact requests in redacted structural form, negative/fault results, independent review, exact-head CI, native runs, and post-merge verification.
