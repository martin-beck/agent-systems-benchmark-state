# AR-1243: Assemble and sign installable runtime bundles

## Outcome

Provide a reproducible release command that builds the ASB loopback supervisor and sidecar for a
declared target, creates the canonical runtime-bundle inventory/SBOM, signs `manifest.json` with the
configured `asb-runtime-bundle-v1` SSH signing key, and emits an installable archive plus detached
signature/trust metadata.

## Dependencies and ownership

Dependencies: AR-1239, AR-1240, AR-1241. Repository: `martin-beck/agent-systems-benchmark`.
Own only bundle packaging/signing tooling, release fixtures, and bundle documentation. Do not
change runtime isolation or TUI code.

## Acceptance

- Reproducibly build both helpers from the exact pinned source revision with safe executable modes.
- Generate complete manifest, SPDX/CycloneDX inventories, and SHA-256 content digests.
- Sign canonical manifest bytes with an explicit operator-selected SSH key and namespace.
- Verify the staged bundle offline before atomic archive publication; fail closed on missing,
  unsigned, mismatched, or cross-target payloads.
- Never expose private key material; support CI/public verification with allowed-signers metadata.
- Add deterministic positive/tamper/target tests and document the install command and provenance.
- Pass locked workspace, format, clippy, rustdoc, DCO/signature, and release-bundle gates.
