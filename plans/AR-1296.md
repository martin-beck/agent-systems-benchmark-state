# AR-1296: Restore state quality-gate coverage and package identity

Repair the state repository's strict mypy and coverage baseline exposed by
AR-1295. The `tools` package is currently discovered under conflicting module
names, and upgrade command modules are entirely untested, leaving coverage at
84% against the unchanged 95% floor.

## Scope and decision gate

Make package identity explicit and preserve the existing import contract for
the handoffctl entrypoint. Add bounded offline tests for upgrade planning,
validation, and failure paths, plus any small missing branches needed to reach
the existing coverage floor. Do not omit modules, lower thresholds, add
runtime dependencies, or change handoffctl behavior without contract tests.

## Acceptance

- Strict mypy over the documented tools/tests scope passes without global
  ignores or import suppression.
- Full state tests and coverage meet the existing 95% line/branch requirement,
  with positive, malformed, unknown-field, and failure-path tests.
- Vendor verification, privacy, signatures/DCO, and live doctor remain green;
  no ASB product, asb-tui, formal semantics, or handoffctl extraction changes.
