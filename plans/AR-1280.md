# AR-1280: Cross-crate replay process entrypoint

## Outcome

Add the reviewed cross-crate runtime-to-CLI process entrypoint required for authenticated primary
strict replay, starting from protected main and implementing the transport rather than auditing it.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1275 through AR-1279 are blocked evidence only and their
branches are not inputs. Owned paths: asb-core protocol, asb-runtime supervised process bridge,
asb-cli primary command entrypoint, and executable lifecycle fixtures/tests. Branch:
`feature/ar-1280-cross-crate-replay-entrypoint`; worktree:
`agent-systems-benchmark-ar-1280-cross-crate-replay-entrypoint`.

## Acceptance

Implement an authenticated bounded IPC/process handoff that issues runtime-owned clients to the
actual argument-level replay command. Prove real supervised cassette request/response, egress
denial, no fallback, cancellation/restart, timeout/crash reaping, cleanup, and malformed/stale/
duplicate rejection. Run full locked gates, independent review, exact-head CI, signed merge, and
post-merge assurance. A fresh-main audit alone is not completion; implement the entrypoint or
record a concrete external blocker with attempted evidence.
