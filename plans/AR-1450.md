# AR-1450: Runtime-owned local replay acquisition factory

Add a runtime-owned local deterministic replay acquisition factory below asb-runtime. It accepts only a validated cassette digest and returns an opaque one-shot ReplayLaunchAuthority. Lease, relay, sandbox input, NetworkPolicy::Deny, backend attestation, cancellation and teardown remain inside runtime. Integrate the ordinary ASB CLI only through this opaque API after AR-1449.

Dependencies: AR-1448. Do not touch asb-tui or require live providers or native hosts.
