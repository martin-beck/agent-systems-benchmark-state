# AR-1267: Runtime strict-replay execution hook

## Outcome

Implement the missing runtime-owned strict-replay execution hook that accepts an authenticated
dispatch context, serves approved cassette request/response traffic, and supervises lifecycle and
network isolation. This is the capability required by AR-1266; metadata validation alone is not
execution evidence.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1266 remains blocked design evidence and its unmerged
branch is not an input. Owned paths: ASB runtime/replay execution, cassette service, CLI integration,
schemas/fixtures, and tests. Branch: `feature/ar-1267-runtime-replay-execution`.
Worktree: `agent-systems-benchmark-ar-1267-runtime-replay-execution`.

## Work sequence

1. Define a bounded runtime-owned execution API consuming opaque authenticated dispatch context and
   an immutable cassette; reject caller-supplied endpoints, readiness, commands, leases, and digests.
2. Implement real credential-free request/response execution through the supervised sidecar and
   prove route identity, provider and descendant egress denial, no live fallback, and bounded output.
3. Add cancellation/restart, timeout/crash reaping, stale/duplicate/forged context, malformed
   cassette, and cleanup/no-leak tests through the actual CLI replay command.
4. Run repeated focused tests, full locked offline gates, policy/privacy/schema/signature/DCO,
   independent review, exact-head CI, signed merge, and all post-merge workflows.

## Acceptance criteria

The actual replay command performs real cassette request/response under runtime supervision and
fails closed on every listed lifecycle, authority, egress, malformed, and fallback case. No
metadata-only or fabricated readiness evidence is accepted.
