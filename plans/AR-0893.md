# AR-0893: Document CLI setup for LLM doubles and local inference

## Outcome

Deliver concise executable CLI-only setup/troubleshooting for selected synthetic and local profiles, with explicit labels and no invented commands/capabilities.

## Dependencies and ownership

Depends on AR-0890, AR-0891 and AR-0892, AR-0869, AR-0871 and AR-0872. Own CLI help if required, setup/preflight, CLI workflow docs, public examples and doc tests. No TUI changes. Branch `docs/cli-local-llm-setup`; worktree `agent-systems-benchmark-cli-local-llm-setup`.

## Work sequence

1. Derive commands from shipped help/support catalogs; separate install, verify, select, run, report/compare and teardown.
2. Provide credential-free synthetic and qualified local-live paths with pins/digests, loopback/resource requirements, model verification and recovery.
3. Explain evidence labels and cross-link existing multi-agent/replay workflows instead of duplicating them.
4. Diagnose missing binary/model, wrong digest/version/template/backend, port conflict, non-loopback listener, inherited credentials, unsupported routes and resources.
5. Execute command blocks in CI with public fixtures or provisioned qualified local jobs; failed/skipped runs cannot publish success.
6. Keep beginner prose concise; claim no TUI screen, shortcut or unfinished record/replay UI.

## Acceptance criteria

Clean supported environments follow exact steps; bad identity/network/resources fail before launch; examples match executable help/results; privacy holds; labels are unambiguous; unsupported candidates remain absent; and CLI stays separate from TUI.

## Evidence and completion

Record help snapshots, command execution, pin/model verification, negative preflight/privacy/link tests, full gates, immutable review, exact-head CI, post-merge verification and AR-0873/0874 handoff.
