# AR-1215: Multi-agent result comparison tutorial

Create the tutorial for comparing two or more agents on the same benchmark definition. Show exact
benchmark/workload/measurement identity, compatible configuration and provenance, selection of
run IDs, report generation, and conservative handling of missing, failed, or incomparable results.

CI validates the tutorial syntax and synthetic report fixtures offline. It must reject examples that
silently compare different benchmark definitions or drop failures from the denominator.
