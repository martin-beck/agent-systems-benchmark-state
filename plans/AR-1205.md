# AR-1205: OpenRouter free-model live/replay conformance and parity evidence

## Outcome

Prove each supported agent against the pinned OpenRouter free model through a credential-free
loopback conformance suite and native loopback live-record → network-denied-replay journeys, and
record free-model availability/limits.

## Dependencies and ownership

Dependencies: AR-1200 (pinned OpenRouter profile), AR-1203 (replay-mode run/sweep), AR-1204
(integrated workflow). Repository: `martin-beck/agent-systems-benchmark` only. Owned paths are the
parity module in `crates/asb-agents` (OpenRouter rows), provider conformance fixtures,
`docs/PROVIDER_PARITY.md` and support-matrix cells, and the replay conformance extension for
OpenRouter dialects. Branch: `feature/openrouter-conformance`. Worktree:
`agent-systems-benchmark-openrouter-conformance`.

## Work sequence

1. Build the credential-free synthetic loopback suite for the OpenRouter dialect (Chat
   Completions/Responses buffered + SSE, tools, causal IDs, retries, errors).
2. For each supported agent: live-record one workload against the free model in a loopback-only
   user/network namespace, then stop the provider and run strict replay; require edit/grader parity
   and no outbound network.
3. Record free-model observations (availability, rate limits, latency variability) as explicit
   evidence limits; never claim fresh-model quality from replay.
4. Update parity and support-matrix cells; keep unproven combinations unsupported.

## Acceptance criteria

Each supported agent has a passed live-record → offline-replay journey with exact trajectory/grader
parity; mismatched/unsupported dialect fails closed; no credential or prompt is retained in
evidence; free-model limits are documented; Gemini remains unsupported for the OpenAI-compatible
profile.

## Evidence

Per-agent journey logs, parity matrix, replay conformance results, negative fixtures, exact-head CI
(credential-free parts) + controlled-host live evidence.
