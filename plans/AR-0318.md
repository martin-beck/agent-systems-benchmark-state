# AR-0318: Implement the credential-reference boundary

## Outcome

Resolve an explicitly allowlisted environment, file-descriptor, or helper reference, bind the canonical non-secret locator metadata to the declared `reference_sha256`, and inject the resolved value only at the bounded provider process boundary. Ambient credentials and secret material must never enter argv, persisted state, logs, reports, or frontend responses. The digest is never computed over credential bytes.

## Dependencies and ownership

Dependencies: AR-0102, AR-0310. Owned paths: the credential-resolution crate, privacy-safe fixtures, and its focused documentation/tests. Cargo workspace and schema registration are coordinator-serialized. Branch: `feature/credential-reference-boundary`. Worktree: `agent-systems-benchmark-credential-reference-boundary`.

## Acceptance criteria

1. Support only explicit, versioned reference kinds with bounded size, time, lifetime, and one-shot semantics; canonicalize non-secret locator metadata and verify it against `reference_sha256` before resolving. Resolved bytes are checked only for configured bounds and non-empty validity, never persisted or hashed into the locator digest.
2. Keep secrets out of argv, environment snapshots, persisted plans/results, logs, diagnostics, API responses, and crash artifacts; prevent ambient-environment bleed and concurrent cross-run mixing.
3. Fail closed for missing, duplicate, stale, or wrong-digest references; and for symlink, non-regular, or insecure file sources when a trusted opener is used. File-descriptor references must arrive as an already-open `OwnedFd` whose owner, mode, type, and one-shot use are checked; the resolver does not claim to prove pre-open path traversal. Also fail closed for helper timeout, nonzero exit, oversize output, malformed protocol, cancellation, and cleanup failure.
4. Add deterministic fixtures and negative/concurrency/cancellation tests proving cleanup and bounded behavior without storing secret values.
5. Document the supported reference contract and explicit unsupported combinations. AR-0314 live preflight, AR-0804 settings, and AR-0821 installation may not claim credential support until this AR is complete.

## Evidence and completion

Record focused and full checks, privacy and dependency scans, immutable signed+DCO commits, exact-head CI, review, and post-merge verification. Do not claim provider live support from logical digests alone.
