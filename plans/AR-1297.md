# AR-1297: Repair task-schema and coordination metadata consistency

Restore the repository-wide schema/generated-state gate exposed by AR-1296.
Historical task records contain empty observed heads, valid coordinator
`superseded_by` pointers rejected by the published schema, and overlong
next-action text.

## Scope and decision gate

Audit every failing task against its durable evidence. Add `superseded_by` to
the versioned schema only with the same strict identifier/graph constraints
already enforced by handoffctl. Fill missing observed heads only from verified
commit evidence (or a truthful current state head for state-only tasks); never
invent hashes. Shorten next actions without dropping blockers or acceptance
requirements. Update validator tests and regenerate views through handoffctl.

## Acceptance

- `tests/validate_schema.py`, render-status check, full state tests, privacy,
  and live doctor pass with no broad schema relaxation.
- Every repaired metadata field has durable evidence, valid 40-hex identity,
  bounded next action, and correct supersession graph.
- Signed/DCO state commit and independent review are complete; no ASB product,
  asb-tui, handoffctl implementation, or formal-gate weakening changes.
