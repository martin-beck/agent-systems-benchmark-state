# AR-1304 plan: required-tier QEMU user-bus runner

## Objective

Provide a clean, deterministic CI/VM runner for the required TLC containment
tier so AR-1293 can produce a truthful `pr-publication` attestation. Preserve
the already-qualified portable lane and fail closed whenever the guest user
bus or transient unit cannot be established.

## Scope

State formal-runner and QEMU guest-launcher tooling only. Use the exact signed
AR-1293 candidate checkout and pinned TLC/JDK inputs. Keep all images, overlays,
seeds, logs and evidence under `/srv/data/projects`; do not modify product
code, asb-tui, handoffctl, or host admission locks.

## Required work

1. Build a fresh disposable x86_64 QEMU image from reviewed immutable inputs;
   use 32 GiB RAM, 8 vCPUs, 16 GiB guest swap, `-net none`, no host mounts,
   UUID-identified data storage, bounded timeout and deterministic cleanup.
2. Establish and verify the guest user runtime and D-Bus session before any
   `systemd-run --user` invocation; capture only sanitized status evidence.
3. Run required TLC with `MemoryMax=3G`, `MemorySwapMax=3G`, `CPUQuota=200%`,
   `TasksMax=64`, `KillMode=control-group`, and `RuntimeMaxSec=1800`.
4. Add positive and negative tests for bus setup, transient-unit launch,
   missing-bus fail-closed behavior, exact resource properties, and offline
   operation. Do not replace required containment with portable limits.
5. Produce a required `pr-publication` attestation for the exact candidate;
   only then allow AR-1293 to run `full-exhaustive`.

## Acceptance gates

- Focused runner/seed tests, full applicable state suite, Ruff, mypy and
  vendor verification pass.
- Required `pr-publication` attestation is green and binds exact source,
  image/JDK/JAR digests, guest bus readiness and all resource properties.
- Independent exact-head review confirms privacy, provenance, cleanup and no
  gate weakening; signed SSH conventional commits include DCO.
- Any unavailable user bus, stale image, mismatched commit or missing property
  fails closed with an actionable durable next action.

## Non-goals

No native ARM64 requirement, no host-specific dependency, no runtime download,
no telemetry, no raw logs or private paths in public evidence, and no changes
to product capability or asb-tui.
