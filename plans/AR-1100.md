# AR-1100: Implement authoritative configuration and defaults

## Outcome

Add versioned ASB configuration, atomic persistence and shared or per-agent defaults.

## Dependencies and ownership

Dependency: AR-0313. AR-0314 and AR-0320 are required design inputs, not implementation blockers. Repository: `martin-beck/agent-systems-benchmark`. Owned paths: configuration types and schemas, XDG store, effective-value resolver, migrations, defaults and tests.
Branch: `feature/ar-1100`. Worktree: `agent-systems-benchmark-ar-1100`.

## Work sequence

1. Define separate agent, connection, authentication-reference, model-profile, global-default, per-agent-override and run-override records.
2. Store bounded non-secret configuration atomically in an owner-private XDG file with explicit migrations and corruption recovery.
3. Resolve built-in, global, per-agent and run-only precedence and show the origin of every effective value.
4. Apply one profile to all or selected agents atomically; reject the whole change when any target is incompatible.
5. Attack malformed schemas, unsafe links, partial writes, concurrent updates and secret-shaped input.

## Acceptance criteria

ASB has one authoritative durable configuration; shared defaults and explicit overrides survive restart, failed changes preserve the last valid state, and credential values cannot enter the schema or store.

## Evidence and completion

Record bounded public fixtures, exact schema and repository identities, focused/full gates, privacy scans, independent immutable-head review, exact-head CI and post-merge verification. Never publish credentials, prompts, responses, private paths, host identities or raw logs.
