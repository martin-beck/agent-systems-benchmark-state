# AR-1240: Native signed-bundle supervisor fixture

## Outcome

Provide a deterministic native test fixture that materializes and verifies a signed supervisor /
sidecar bundle before Bubblewrap execution.

## Dependencies and ownership

Dependencies: AR-1238 and AR-1239. Repository: `martin-beck/agent-systems-benchmark`. Own only
the native fixture installer and end-to-end isolation tests; do not weaken bundle verification or
runtime ownership boundaries.

## Acceptance

- Build or materialize both verified executable payloads without mutable host paths or symlinks.
- Verify the canonical manifest/signature offline before launch and pass verified paths/digests to
  SandboxBackend.
- Prove cassette success, provider/descendant egress denial, timeout/cancellation teardown,
  descendant reaping, and unrelated-process non-interference under native Bubblewrap.
- Skip only with explicit, bounded capability evidence; never enable host networking, firewall
  mutation, ambient `ip`, credentials, or privileged setup.
- Locked tests, format, clippy, rustdoc, signature/DCO, exact-head, and post-merge evidence.
