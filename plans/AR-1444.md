# AR-1444 — First-class journey qualification and release gate

## Scope

Qualify the complete clean-install → wizard → benchmark → offline replay →
comparison journey across ASB and asb-tui at pinned compatible revisions.
Publish a small support matrix and make the journey a release gate with
credential-free local qualification plus optional operator-only live evidence.

## Dependencies

Depends on AR-1443. The paired asb-tui acceptance AR-1327 must be complete
before release qualification is declared green.

## Acceptance

- A disposable user can complete the journey with a short sequence of visible
  choices and no documentation lookup.
- CLI/TUI protocol, bundle, catalog, authentication, campaign, replay, and
  comparison versions are checked before launch and give one actionable error.
- The support matrix distinguishes build-only, simulated, replayed, live, and
  unsupported combinations; no external key or response is persisted.
- Upgrade/rollback and interrupted-run recovery are included in the release
  qualification.

## Required evidence

Exact pinned ASB/asb-tui revisions, clean disposable transcript, all required
CI and independent review, signed+DCO publication, and post-merge rerun.
