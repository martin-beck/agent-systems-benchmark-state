# AR-1733 — cli2key qualification and documentation

Create a reproducible end-to-end receipt for setup through results using the
fake sidecar, plus a separately authorized live-development receipt that stores
only redacted/digest evidence. Verify no leaked key or OAuth material, no
remaining listener/process/private staging, exact result provenance, and typed
failure behavior. Add user documentation for prerequisites, login boundary,
selection, run, sweep, status, reset, revocation, troubleshooting, cost/quota,
and methodology limits. This AR does not promote a release channel.
