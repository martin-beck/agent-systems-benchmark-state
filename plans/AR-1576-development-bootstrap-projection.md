# AR-1576 development bootstrap projection

Provide the credential-free development backend responses required by the
current asb-tui bootstrap projection: capabilities, benchmark and measurement
catalogs, history, agent catalog, lifecycle status, and provider/configuration/
recording status where the negotiated protocol requests them. Responses must
be bounded, typed, development-only fixtures and must not claim production
authentication or live provider access. Stable control behavior remains
unchanged.
