# AR-0872: Publish beginner workflow documentation

## Outcome

Create a concise linked workflow hub under `docs/workflows/` that lets a new user complete equivalent benchmark journeys with either the CLI or the TUI.

## Dependencies and ownership

Dependencies: AR-0802, AR-0869, AR-0870, AR-0871.
Owned paths: `docs/workflows/README.md`, beginner CLI/TUI guides, multi-agent/provider guide, record/replay guide, troubleshooting, and documentation tests.
Branch: `docs/beginner-workflows`. Worktree: `agent-systems-benchmark-beginner-workflows`.

## Work sequence

1. Build a short landing page linking setup, first benchmark, several-agent shared-provider run, progress monitoring, result comparison, recording, replay, recovery, and troubleshooting.
2. Put beginner CLI and TUI routes side by side with copyable commands, exact keys/screens, prerequisites, expected states, and the same public example.
3. Show selecting several agents and one preconfigured provider for all of them, plus explicit alternatives for per-agent profiles.
4. Show recording LLM responses, locating the immutable cassette, replaying it offline, and comparing live versus replay results without overstating comparability.
5. Link advanced references rather than overloading the first-run path; clearly label cost, network, credentials, limitations, and unsupported combinations.

## Acceptance criteria

A fresh user can configure, validate, launch, monitor, finish, and compare a several-agent benchmark using either interface, then record and replay a compatible run; every step is executable against the released binaries; CLI/TUI concepts use the same names; and the landing page keeps the shortest successful paths prominent.

## Evidence and completion

Record fresh-environment walkthroughs, documentation test results, reviewed commands/keys, immutable commit, exact-head CI, and post-merge verification.
