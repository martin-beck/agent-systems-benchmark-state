# AR-1252: Provision an approved isolated qualification runner

## Outcome

Provide a reproducible container-backed runner for ASB executable qualification when the host
cannot create network namespaces, using the available privileged Docker service without exposing
host credentials, paths, or network access to the workload.

## Dependencies and ownership

Dependencies: AR-0003. Own only ASB runner tooling/configuration and qualification integration;
do not modify asb-tui or weaken native/emulated gates.

## Acceptance

- Use an immutable, locally cached OCI image digest and a reviewed wrapper with explicit `--network none`,
  read-only root/filesystem, bounded resources, dropped capabilities, no host network/PID/IPC, and
  a private writable artifact directory under `/srv/data/projects`.
- Verify image digest, runner identity, command/timeout limits, process-tree cleanup, and no secret or
  private-path leakage; reject mutable tags, host inference, arbitrary mounts, shell commands, and egress.
- Demonstrate the runner with deterministic positive and negative network-denial/cancellation tests,
  then make it consumable by AR-1251. Run focused/full policy/privacy gates and signed-DCO review.
