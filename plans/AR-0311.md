# AR-0311: Support a shared OpenAI provider

## Outcome

Configure every compatible ASB agent adapter with the same normalized default OpenAI provider profile.

## Dependencies and ownership

Dependencies: AR-0301 through AR-0310 as listed in the task metadata.
Owned paths: OpenAI provider profile, adapter translations, synthetic service fixtures, and provider-specific documentation.
Branch: `feature/provider-openai`. Worktree: `agent-systems-benchmark-provider-openai`.

## Work sequence

1. Pin the OpenAI profile semantics and default endpoint behavior without embedding credentials.
2. Translate the profile through every supported agent's documented configuration boundary.
3. Use a disposable synthetic OpenAI-compatible service to observe effective model, settings, streaming, tool calls, retries, cancellation, and redaction.
4. Test absent credentials, unsupported settings, malformed responses, endpoint mismatch, cancellation, and secret non-disclosure.
5. Publish a per-agent support/limitation matrix backed by immutable tests and exact-head CI.

## Acceptance criteria

Each supported adapter sends the same requested model and normalized settings or is explicitly marked unsupported before launch; authentication comes only from secret references; default OpenAI behavior cannot be confused with an arbitrary compatible endpoint; partial all-agent configuration is rejected; and real connection tests are opt-in and never required for offline CI.

## Evidence and completion

Record pinned agent/provider versions, request-field observations with sensitive values redacted, immutable commits, independent review, CI, and unsupported combinations. README claims alone are insufficient.
