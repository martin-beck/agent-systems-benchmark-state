# AR-0319: Implement credential FD and helper resolvers

## Outcome

Support explicitly configured `file_descriptor` and `helper` credential references with no ambient fallback, while preserving the non-secret locator digest contract and bounded process injection established by AR-0318.

## Dependencies and ownership

Dependency: AR-0318. Owned paths: credential boundary implementation, fixtures, focused tests, and documentation. Branch: `feature/credential-fd-helper-resolvers`. Worktree: `agent-systems-benchmark-credential-fd-helper-resolvers`.

## Acceptance criteria

1. Define canonical non-secret locator metadata and verify its digest before lookup; never hash or persist credential bytes.
2. FD references require an already-open one-shot `OwnedFd`; validate owner, mode, regular-file/type and bounded read, with explicit cleanup and no claim about pre-open path traversal.
3. Helper references use a bounded versioned protocol with allowlisted executable identity, deadline, output-size limit, cancellation, nonzero/malformed/oversize failure, and cleanup.
4. Add negative tests for missing, stale, wrong-digest, duplicate, insecure, concurrent, cancelled, and ambient-environment cases. Secrets never appear in argv, logs, plans, results, diagnostics, or frontend responses.
5. Run focused/full quality, privacy, dependency, fuzz, and recovery gates; publish only a signed+DCO checkpoint with exact-head CI and explicit unsupported combinations.
