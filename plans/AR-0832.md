# AR-0832: Qualify development host ASB runner operations

## Outcome

Independently prove that development host ASB runners and their GitHub workflow routing are reproducible,
isolated, recoverable, and honest about architecture and platform support.

## Dependencies and ownership

Dependencies: AR-0830, AR-0831, AR-0703.
Owned paths: disposable qualification harnesses, runner/workflow support matrix, recovery evidence,
artifact provenance checks, and operational qualification documentation.
Branch: feature/development-host-runner-qualification. Worktree: agent-systems-benchmark-development-host-runner-qualification.

## Work sequence

1. Execute repeated clean runs for every declared label, architecture, distribution, and trust
   class, binding source, toolchain, runner image, kernel, job, and artifact digests.
2. Inject runner loss, reboot, network interruption, timeout, cancellation, full disk, stale
   lease, cache corruption, process escape, malformed artifact, and workflow routing failures.
3. Verify reset and orphan cleanup, exact artifact reproducibility, SBOM/provenance, privacy
   redaction, and no impact on existing Relay runners.
4. Compare development host and disposable GitHub-hosted results for supported jobs; mark differences and
   unsupported combinations explicitly instead of inflating support.

## Acceptance criteria

- Every declared development host runner label has repeated green evidence and a bounded failure/recovery
  record; missing capacity remains planned or unqualified.
- Public-PR isolation, protected routing, lease fencing, reset cleanup, and artifact provenance
  pass independent negative tests.
- No benchmark result or support claim depends on an unverified runner, mutable environment,
  hidden cache, host identity, or private diagnostic.
- Exact-head CI, post-merge checks, and independent audit approve the complete runner matrix.

## Evidence and completion

Publish only sanitized manifests, matrices, digests, and bounded logs. Completion requires
immutable review, exact CI, synchronized runner state, and a post-merge qualification rerun.
