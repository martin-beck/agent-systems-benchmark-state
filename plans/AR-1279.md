# AR-1279: End-to-end primary replay runtime handoff

## Outcome

From protected main, implement the authenticated runtime-to-CLI transport and connect it to the
actual argument-level strict-replay command, proving supervised cassette execution end to end.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1275 through AR-1278 are blocked design evidence only;
their unmerged branches are not inputs. Owned paths: asb-core transport, asb-runtime issuer and
supervisor bridge, asb-cli primary replay dispatch, cassette/lifecycle fixtures, and executable
tests. Branch: `feature/ar-1279-end-to-end-replay-runtime`; worktree:
`agent-systems-benchmark-ar-1279-end-to-end-replay-runtime`.

## Acceptance

The primary command fails closed without authenticated runtime context, receives a runtime-issued
client, executes bounded supervised cassette request/response traffic, and proves provider and
descendant egress denial, no live fallback, cancellation/restart, timeout/crash reaping, cleanup,
and malformed/stale/duplicate rejection. Run full locked gates, independent review, exact-head CI,
signed merge, and post-merge assurance. Do not reuse blocked feature branches.
