# AR-0869: Add CLI multi-agent provider selection

## Outcome

Provide discoverable noninteractive options that select several configured agents and atomically apply one preconfigured provider profile to all of them.

## Dependencies and ownership

Dependencies: AR-0313, AR-0318, AR-0320, AR-0801.
Owned paths: CLI agent/provider selection, plan rendering, validation, help, examples, and focused tests.
Branch: `feature/cli-multi-agent-provider-selection`. Worktree: `agent-systems-benchmark-cli-multi-agent-provider-selection`.

## Work sequence

1. Add bounded repeatable agent selection and an explicit shared provider-profile option sourced from the advertised catalog.
2. Show the selected agents, provider, model, credential reference kind, effective defaults, and unsupported combinations in dry-run and plan output without exposing secret values.
3. Reject empty, duplicate, unknown, incompatible, mixed-profile, and stale catalog selections before creating or launching a plan.
4. Keep exact manifest import available and make CLI help include copyable multi-agent examples.
5. Test OpenAI, Ollama, unavailable profiles, noninteractive failure behavior, redaction, stable JSON, shell completion, and compatibility with run, sweep, compare, and report.

## Acceptance criteria

A new user can select multiple supported agents and one preconfigured provider with command-line options alone; the same validated profile applies to every selected agent; no fallback silently changes provider or credentials; dry-run has no launch or provider effect; and generated plans remain content-pinned and reproducible.

## Evidence and completion

Record help snapshots, structured-plan fixtures, positive and negative executions, signatures/DCO, immutable review, exact-head CI, and post-merge verification.
