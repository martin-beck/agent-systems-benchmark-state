# AR-1274: Runtime cassette operation executor adapter

## Outcome

Add a dependency-neutral runtime cassette operation executor/callback boundary that can receive a
validated request envelope and return a validated response envelope while keeping cassette decoding
and strict replay implementation in the CLI/replay layer.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1273 is blocked design evidence and its unmerged branch
is not an input. Owned paths: shared operation executor contract, runtime callback registration and
supervision, CLI/replay adapter, and executable tests. Branch:
`feature/ar-1274-runtime-cassette-executor-adapter`. Worktree:
`agent-systems-benchmark-ar-1274-cassette-executor`.

## Work sequence

1. Define a bounded trait/object-safe operation executor in dependency-neutral core using only
   CassetteRequestV1/CassetteResponseV1 and authenticated service identity. Reject unknown fields,
   credentials, unbounded bodies, stale/duplicate operations, and live fallback.
2. Have runtime issue/register the executor only from authenticated launch context, retain it under
   lifecycle ownership, and supervise bounded calls/cancellation/restart/timeout/crash cleanup.
3. Implement a CLI/replay adapter that decodes immutable cassette bytes and supplies only validated
   envelopes. Prove real request/response parity, provider/descendant egress denial, no-fallback,
   cancellation/restart, timeout/crash reaping, and cleanup/no-leak behavior through actual dispatch.
4. Run full locked offline gates, policy/privacy/schema/signature/DCO, independent review, exact-head
   CI, signed merge, and all post-merge assurance workflows.

## Acceptance criteria

The actual replay command executes real cassette traffic through a runtime-owned executor boundary;
no crate cycle or caller-provided authority remains, and every lifecycle/egress failure path is
bounded and fail closed.
