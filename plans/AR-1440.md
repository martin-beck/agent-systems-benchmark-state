# AR-1440: Refresh OpenRouter model pin and local measurements

## Objective

Replace the unavailable dated free-model pin with a currently listed free
OpenRouter model, preserve a dated immutable identity, and qualify a bounded
local measurement campaign without changing credential-free CI.

## Dependencies and boundaries

AR-1328, AR-1436, and AR-1437 are complete. The live runtime execution chain
AR-1329 remains blocked and must not be resumed or bypassed. This AR may use
the explicitly authorized local key only in an operator process; no key,
response, prompt, header, endpoint token, or private path may enter source,
state, CI, evidence, or committed artifacts.

## Required work

1. Probe the provider catalog and select a model whose identifier is explicitly
   free; record its date and exact snapshot identity.
2. Update every profile/config/fixture/generated-doc reference and add positive
   and negative tests for the new identity and stale-pin rejection.
3. Add or use a local-only bounded measurement command for selected ASB
   workloads; retain digest-only typed results and clean up transient data.
4. Run focused and full applicable offline gates, then run the authorized local
   live smoke/measurement separately. Do not add networked CI steps.
5. Publish a signed+DCO PR, require exact-head CI and post-merge verification,
   then release the AR with the live catalog and measurement evidence.

## Acceptance

The refreshed pin is available in the live free catalog and all offline
contract tests pass. Local measurements succeed or fail with redacted bounded
evidence, while CI remains credential-free and the blocked runtime-owned live
execution boundary remains unchanged.
