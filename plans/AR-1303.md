# AR-1303 plan: privacy-safe hosted platform failure diagnostics

## Objective

Make hosted platform evidence failures diagnosable without exposing subprocess
output, private paths, credentials, or weakening any gate. Preserve the current
fail-closed result and keep native qualification independent from hosted
portability.

## Scope

ASB CI/platform evidence tooling only: `tools/platforms/hosted_portability.py`,
its focused tests, workflow contract tests, and the hosted workflow. No runtime,
asb-tui, schema-claim, or native-qualification weakening changes.

## Evidence and problem

AR-1301 PR #219 at `6221b894c438292ff50b21d2d0c27a875d0bcc1b` passed all other
required checks, but hosted platform jobs `105192558571` and `105195340454`
failed with the same generic sandbox message. The exact local collector passed
with process=712, metrics=903, and sandbox=1384 output bytes. The helper currently
collapses spawn, nonzero, timeout, output-limit, and related failures into one
message.

## Required work

1. Classify failures with a closed set: `spawn`, `nonzero`, `timeout`,
   `output_limit`, `source_race`, `unavailable`, `evidence`, and `unknown`.
2. Add an explicitly opt-in hosted-workflow diagnostics mode that emits only the
   stable check slot and fixed class; never emit command output, arguments,
   paths, environment values, credentials, prompts, or raw logs.
3. Preserve the existing nonzero exit and fail-closed artifact validation.
4. Keep successful evidence byte/schema-compatible and native qualification
   behavior unchanged.
5. Add positive and negative tests for every class, privacy tests, and a workflow
   contract test proving diagnostics are opt-in and all three checks remain.

## Acceptance gates

- Focused and full applicable Python/platform tests pass.
- Exact hosted collector still passes all three checks locally.
- Native qualification remains green with required capability enabled.
- Failure injection proves every class and no raw subprocess output is retained.
- Independent exact-head review verifies privacy and no gate weakening.
- Signed SSH conventional commit with DCO, clean PR, exact-head green CI,
  post-merge verification, and durable state evidence.

## Non-goals

No runtime behavior changes, no asb-tui changes, no telemetry, no network or
runtime dependencies, and no conversion of a failed platform check into success.
