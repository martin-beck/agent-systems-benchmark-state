# AR-0812: Deliver modern adaptive terminal rendering

## Outcome

Make `asb-tui` feel clean, premium, fast, and visually coherent by using modern terminal features only after safe capability negotiation.

## Dependencies and ownership

Dependencies: AR-0804, AR-0805, AR-0806.
Owned paths: terminal/channel capability model, renderer/themes, responsive layouts, charts, input enhancements, fallbacks, and visual/performance tests.
Branch: `feature/modern-terminal-rendering`. Worktree: `agent-systems-benchmark-modern-terminal-rendering`.

## Research-derived design constraints

Ratatui's retained double-buffer/diff rendering and deterministic test backend motivate a pure state-to-frame renderer with snapshot tests. Zellij's independent client/server, local-socket framing, resize handling, and reattach behavior motivate strict frontend isolation and reconnect. K9s demonstrates command/search modes, contextual help, read-only operation, configurable views/hotkeys, and themes for efficient expert use. Crossterm exposes resize, focus, bracketed paste, mouse, RGB colors, synchronized updates, and progressive keyboard enhancement, all of which require explicit enable/disable cleanup and fallbacks.

## Work sequence

1. Detect the actual channel as structured evidence: TTY/ioctl size, TERM/TERM_PROGRAM/COLORTERM, SSH_CONNECTION/SSH_TTY, TMUX, STY, nesting, locale/width behavior, NO_COLOR, and conservative active terminal queries with strict timeouts. Treat environment hints as untrusted and allow explicit overrides/diagnostics.
2. Select a named capability tier and render policy: plain/8-color, 256-color Unicode, or modern truecolor. Use a stable spacing/type scale, restrained semantic palette, strong focus hierarchy, compact tables, progressive disclosure, sparklines/charts with numeric equivalents, OSC 8 links, bracketed paste, focus events, optional mouse, and unambiguous enhanced keys.
3. Use alternate screen, cursor lifecycle, cell-diff/double buffering, damage-limited redraw, frame coalescing, optional synchronized output, and bounded refresh rates. Inline Kitty/Sixel/iTerm graphics are optional enhancements only after verified passthrough and must have equivalent text rendering.
4. Handle SIGWINCH and resize events by querying authoritative current size, debouncing/coalescing bursts, recomputing responsive breakpoints, preserving focus/selection/scroll state, clearing stale cells, and never trusting stale event dimensions. Support tiny terminals with a useful compact view instead of panic or corruption.
5. Restore raw mode, cursor, paste/focus/mouse/keyboard enhancements, synchronized output, colors, title, and screen buffer after normal exit, panic, signal, suspend/resume, SSH loss, multiplexer detach/reattach, or failed capability probe.
6. Test byte-level escape output, Unicode width/graphemes, RTL/combining/emoji boundaries, tmux/screen passthrough, SSH latency/bandwidth, rapid resize storms, alternate-screen restoration, light/dark/NO_COLOR/high-contrast themes, snapshot stability, and render CPU/memory/I/O budgets.

## Acceptance criteria

The modern tier is polished and flicker-free on verified terminals; tmux, screen, nested sessions, and SSH choose safe policies without hidden network binding; every visual encoding has a readable text/numeric equivalent; resize from 1x1 through large screens never panics, indexes out of bounds, leaves stale cells, or loses draft state; keyboard-only operation is complete; colors meet measured contrast targets; unsupported sequences are never emitted speculatively; rendering cannot materially perturb benchmark measurements; and `asb-tui doctor --terminal` explains detected evidence, chosen tier, overrides, and limitations.

## Evidence and completion

Pin and inspect terminal dependencies/licenses; record tested emulator/multiplexer/SSH versions, capability transcripts without private host data, golden frames, escape-stream tests, resource comparisons attached versus detached, immutable commits, independent design/UX/accessibility review, exact-head CI, native platform runs, and post-merge verification.
