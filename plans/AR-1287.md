# AR-1287: Delegated sandbox runner capability

## Outcome

Provide a reproducible container or VM runner with the namespace, systemd-scope, CPU lease,
and denied-egress capabilities required to execute the real ASB strict-replay child lifecycle.
This is ASB infrastructure only and excludes asb-tui.

## Dependencies and scope

Depends on blocked AR-1286 for the exact capability evidence. The runner must remain under
`/srv/data/projects`, use pinned offline inputs, expose no credentials or private host paths, and
be invoked by the existing ASB handoff workflow. Prefer an existing permitted container/VM
mechanism; do not weaken sandbox gates or replace the qualified backend with an ignored test.

## Acceptance

- A documented, reproducible container/VM runner starts from pinned local inputs and proves the
  exact bwrap/systemd scope capability, CPU/resource lease, and denied-egress behavior.
- AR-1286's positive bounded child probe runs there without ignored coverage; cancellation,
  timeout, crash/restart cleanup, descendant egress denial, and unrelated-process tests are
  executable with bounded privacy-safe evidence.
- No runtime downloads, credentials, private paths, host data, or weakened native gates.
- Runner setup, focused/full gates, independent review, signed+DCO PR, exact-head CI, protected
  merge, and exact-main post-merge verification are recorded. If impossible, leave precise
  capability evidence and split a narrower successor.
