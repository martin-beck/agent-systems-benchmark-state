# AR-1028: Generate ASB CLI workflow captures

## Outcome

Produce deterministic, privacy-safe command transcripts from real ASB CLI workflows while keeping
all interactive rendering and screenshots in the standalone asb-tui repository under AR-0873.

## Dependencies and ownership

Dependency: AR-0872. Repository: `martin-beck/agent-systems-benchmark`. Owned paths: CLI scenario
harness, synthetic public fixtures, text transcripts, provenance manifests, and documentation
checks. No terminal renderer or TUI application path is owned.

## Work sequence

1. Execute documented configure, validate, run, status, history, compare, replay, and export commands
   against synthetic public fixtures.
2. Normalize locale, time, IDs, paths, and release metadata without fabricating successful output.
3. Publish complete linear transcripts with exact ASB revision and scenario provenance.
4. Scan outputs for secrets, private paths, prompts/responses, and unstable identifiers.
5. Fail CI when scenarios fail, skip unexpectedly, drift from documentation, or cannot reproduce.

## Acceptance and evidence

Every transcript is generated by the exact documented ASB CLI, is deterministic and privacy-safe,
and contains no asb-tui renderer output. Record fixture/tool hashes, CI run evidence, immutable
review, exact-head CI, and post-merge regeneration.
