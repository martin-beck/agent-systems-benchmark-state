# AR-1011: Deliver TUI UX quality features

## Outcome

Make common ASB workflows easy for beginners and efficient for experts without inventing capabilities the negotiated runner does not advertise.

## Dependencies and ownership

Dependencies: AR-1010, AR-0807, AR-0870, AR-0871.
Repository: `martin-beck/asb-tui`. Owned paths: TUI screens, navigation/actions, help,
selector/search widgets, progress and comparison views, accessibility text, and interaction
fixtures. No ASB product paths are owned.
Branch: feature/tui-ux-quality. Worktree: agent-systems-benchmark-asb-tui-ux-quality.

## Required features

1. Add a global command/search palette with incremental filtering, deterministic matching, clear focus, Escape/back behavior, and an always-visible shortcut hint.
2. Add searchable multi-select lists for agents, providers, workloads, metrics, and compatible recordings; show why unavailable choices are disabled.
3. Provide a beginner path with step indicator, contextual help, safe defaults from negotiated catalogs, back/reset/import/export, validation messages, and explicit review before launch.
4. Provide run progress with per-agent state, elapsed time, bounded resource/attempt counters, cancellation confirmation, reconnect state, and clear terminal outcomes.
5. Provide history/compare views with filters, sortable columns, compatible-run warnings, numeric equivalents for charts, and links to reproducible CLI commands.
6. Support keyboard-only operation, visible focus, high-contrast/light/dark themes, NO_COLOR, screen-reader-friendly plain output, and consistent error language. Mouse is optional.

## Acceptance criteria

A new user can discover and complete setup without memorizing flags; an expert can reach any screen through the palette and keyboard; search/filter state survives resize and backtracking; every action is capability-gated and confirmation-protected; progress never claims runner truth before an authoritative event; and all screens have bounded, privacy-safe text equivalents.

## Evidence

Capture sanitized interaction fixtures, TestBackend snapshots, keyboard-only and accessibility checks, resize/latency probes, beginner usability walkthroughs, exact CLI parity checks, independent UX/security review, exact-head CI, and post-merge verification.
