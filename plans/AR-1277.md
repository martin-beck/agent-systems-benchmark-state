# AR-1277: Runtime-to-CLI replay transport boundary

## Outcome

Define and implement an authenticated, dependency-neutral transport boundary through which the
runtime supplies an operation handle to the primary ASB strict-replay command.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1275 and AR-1276 are blocked design evidence only;
their branches are not inputs. Owned paths: asb-core transport types, asb-runtime issuer/bridge,
asb-cli command wiring, and executable transport/lifecycle tests. Branch:
`feature/ar-1277-runtime-cli-replay-transport`; worktree:
`agent-systems-benchmark-ar-1277-runtime-cli-replay-transport`.

## Acceptance

The transport authenticates runtime-issued context, bounds and validates request/response
envelopes, rejects caller-fabricated/stale/duplicate handles, and lets the primary replay command
execute supervised cassette traffic. Prove egress denial, no live fallback, cancellation/restart,
timeout/crash reaping, cleanup, and malformed input. Run full locked gates, independent review,
exact-head CI, signed merge, and post-merge assurance.
