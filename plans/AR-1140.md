# AR-1140: Build CLI first-run and configuration wizard

## Outcome

Add self-explanatory `asb setup` and `asb config` flows while preserving automation.

## Dependencies and ownership

Dependency: AR-1130; AR-1100 through AR-1120 are transitive. Repository: `martin-beck/agent-systems-benchmark`. Owned paths: CLI wizard state, setup/config commands, provider/auth/model selection, default editor, PTY tests and guides.
Branch: `feature/ar-1140`. Worktree: `agent-systems-benchmark-ar-1140`.

## Work sequence

1. Guide installed-agent detection, all/selected agents, provider add/select, authentication, connection, compatible model and workload/source defaults.
2. Show effective values, incompatibilities, network, cost and persistence consequences before confirmation.
3. Implement transactional first setup and later add/edit/disable/remove/reset/import/export operations.
4. Offer apply-to-all only after atomic compatibility preflight and preserve explicit per-agent overrides.
5. Keep non-TTY behavior machine-readable and never make a paid call or persistent change implicitly.

## Acceptance criteria

A clean interactive user can configure ASB without IDs or digests and later change every choice; cancellation leaves no partial state, while scripts retain explicit stable commands.

## Evidence and completion

Record bounded public fixtures, exact schema and repository identities, focused/full gates, privacy scans, independent immutable-head review, exact-head CI and post-merge verification. Never publish credentials, prompts, responses, private paths, host identities or raw logs.
