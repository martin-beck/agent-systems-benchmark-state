# AR-1319 authenticated agent catalog entry contract

## Outcome

Provide a versioned, renderer-neutral catalog contract that can list known
agent identifiers and precise unavailability reasons without inventing target,
package, signer, SBOM, license, or source identities. Only entries with a
complete verified closure may be represented as `available`.

## Scope

ASB control schema and codec, generated schema/fixtures, and focused tests.
Coordinate the matching decoder update in asb-tui AR-1318; do not add a
cross-project dependency to generated state.

## Design obligations

1. Preserve strict decoding and additive protocol/version negotiation.
2. Permit an unavailable entry to omit unverified package/provenance fields,
   while retaining stable agent identity, target evidence when known, bounded
   capabilities when known, and one explicit unavailable reason.
3. Reject `available` entries unless the complete signed package/provenance
   closure is present and validated.
4. Keep canonical digest identity independent of response-only `refreshed` and
   bind generation/runner identity explicitly.
5. Ensure the contract cannot contain credentials, filesystem paths, URLs,
   prompts, or provider traffic.

## Acceptance evidence

- exact JSON fixtures for complete available and incomplete unavailable entries;
- mutation tests for omitted metadata, forged metadata, target mismatch,
  duplicate/unsorted entries, digest changes, and refresh-flag stability;
- locked workspace tests, clippy, schema validation, and exact TUI decoder
  compatibility evidence;
- signed commit and post-merge exact-head verification before AR-1316 claims
  the producer is selectable.
