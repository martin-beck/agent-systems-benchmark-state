# AR-1416: Literature workload local-mock cross-product

## Objective

Exercise each locally executable literature workload through the same lifecycle
as built-in fixtures using deterministic local/LiteLLM-compatible mocks, while
keeping upstream qualification and live-provider access out of development gates.

## Dependencies

- AR-1415 (complete selector/catalog parity)
- AR-1401 (offline literature mock execution)
- AR-1402 (CLI dispatch integration)

## Acceptance

- Every executable literature family has bounded local fixture coverage for plan,
  prepare, run, grade, timeout/reset, record, replay, comparison, and report.
- Interactive, repository/terminal, code-generation, and performance families
  preserve distinct metrics and never pool incompatible scores.
- Unavailable/provenance-only records fail closed before network/provider access;
  local fixtures never upgrade official, native, or evaluator evidence.
- Positive and negative tests cover deterministic replay, malformed manifests,
  stale revisions, timeout/failure evidence, resource limits, and attempted live
  provider/network access.

## Verification

Run focused workload/CLI tests, privacy/formal checks, full workspace quality,
exact-head CI, independent review, and all post-merge assurance workflows.
