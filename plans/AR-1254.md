# AR-1254: Qualify MockAgents through the pinned Python sandbox

## Outcome

Provide a credential-free bounded transport fixture that invokes the real pinned MockAgents
executable through the approved Python runtime and isolated runner.

## Dependencies and ownership

Dependencies: AR-1252, AR-1253. Own only ASB MockAgents transport fixtures, harness integration,
and evidence; preserve AR-1251's blocked history and do not modify asb-tui.

## Acceptance

- Pinned amd64 and arm64 artifacts are selected by explicit digest/platform and run through the
  pinned Python runtime and runner with network-none, one read-only input, bounded resources, and
  cleanup.
- Real executable evidence covers ordered tool results, bounded backpressure/cancellation,
  actual outbound connection denial, malformed input, descendant cleanup, and repeat-clean-state.
- Failure evidence is sanitized/bounded; no credentials, ambient network, fallback provider, or
  unpinned runtime is accepted. Focused/full gates, signed DCO, independent review, exact-head CI,
  protected merge, and post-merge verification pass before release.
