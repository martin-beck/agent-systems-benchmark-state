# AR-1261: Runtime-to-CLI strict-replay handoff entrypoint

## Outcome

Expose a typed, runtime-owned entrypoint that supplies authenticated strict-replay launch
authority to the CLI without allowing caller-created readiness, routes, leases, or commands.

## Dependencies and ownership

Depends on AR-1237, AR-1238, AR-1239, and AR-1260. Keep all existing runtime supervisor and
bundle implementations unchanged unless an explicitly reviewed API fix is required. Owned paths
are the narrow runtime/CLI handoff boundary and focused integration fixtures; do not modify
asb-tui, provider catalogs, or campaign code.

## Acceptance

- Runtime issues opaque authenticated handoff, `SandboxLaunchInput`, `SandboxBackend`,
  `ResourceLease`, route/generation/deadline, and verified supervisor/sidecar commands.
- CLI consumes only that typed entrypoint and invokes `StrictReplayLaunchBridge::spawn`; forged,
  stale, duplicate, route-mismatched, digest-mismatched, or ambient-configured inputs fail closed.
- Real cassette request/response, provider/descendant egress denial, timeout/cancel/crash/restart
  reaping, cleanup, and no-fallback behavior are exercised with bounded evidence.
- Focused/full locked tests, fmt, Clippy, rustdoc, policy/privacy/formal/portability gates,
  signed DCO review, exact-head CI, protected merge, and post-merge verification pass.
