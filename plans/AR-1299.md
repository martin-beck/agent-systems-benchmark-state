# AR-1299: Complete authenticated agent catalog identity metadata

Repository: `martin-beck/agent-systems-benchmark`.

Dependency: AR-1190. This is a bounded correction for issue #164 after audit
found that the merged v1.4 catalog does not explicitly carry signer/key
identity or SBOM/license references required by the issue body.

Own only the ASB control catalog types, v1.4 schemas and credential-free
fixtures, catalog property/privacy tests, and the corresponding contract
documentation. Preserve the existing authenticated operation, exact version
negotiation, runner binding, canonical digest, and separation from lifecycle
effects. Do not add TUI, renderer, coordinator-state, installation, activation,
removal, or agent mutation behavior.

Acceptance:

- each complete agent record has stable identity/version, exact target,
  package digest, explicit signer/key identity, provenance, SBOM and license
  references, capabilities, availability, and a bounded unavailable reason;
- strict schemas and typed validation reject missing/duplicate/malformed,
  secret-bearing, unsupported-target, stale/replayed or mismatched records;
- deterministic complete, incomplete, malformed, capability-mismatch,
  generation/replay, and unavailable fixtures remain credential- and
  private-path-free;
- focused and required repository verification passes, with durable evidence
  and no lifecycle or TUI changes.

Required evidence includes an isolated named worktree, signed DCO commit,
independent exact-head review, CI, and post-change coordinator reconciliation.
