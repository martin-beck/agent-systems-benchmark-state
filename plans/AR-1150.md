# AR-1150: Implement live response recording campaigns

## Outcome

Capture private replay cassettes for selected agents across selected or all implemented workloads.

## Dependencies and ownership

Dependencies: AR-0871, AR-1130. Repository: `martin-beck/agent-systems-benchmark`. Owned paths: recording campaign contract, provider-boundary capture, matrix scheduler, private index, progress and tests.
Branch: `feature/ar-1150`. Worktree: `agent-systems-benchmark-ar-1150`.

## Work sequence

1. Bind agent, connection, model/settings, workload/scorer revision, tool schema and attempt controls into each recording tuple.
2. Expand selected agents and selected or all advertised workloads with a bounded cardinality and maximum cost estimate.
3. Capture buffered and streaming provider interactions while the real agent and workload tools run; redact authorization before sealing.
4. Persist intent and per-tuple state so cancellation or restart never duplicates uncertain paid work.
5. Expose ready, missing, stale, incompatible, partial and failed coverage without captured content.

## Acceptance criteria

Users can explicitly record selected or all current workloads, successful tuples produce authenticated private cassettes, and partial or unsafe captures can never be selected offline.

## Evidence and completion

Record bounded public fixtures, exact schema and repository identities, focused/full gates, privacy scans, independent immutable-head review, exact-head CI and post-merge verification. Never publish credentials, prompts, responses, private paths, host identities or raw logs.
