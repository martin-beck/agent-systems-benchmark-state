# AR-1329: Live-provider run execution for real agents

## Outcome

`asb run` and `asb sweep` execute a real agent process against the selected
provider and workload instead of the digest-pinned `batch-stdio-v1` stub, with
credential-free environment resolution, declared-egress enforcement, and an
explicit opt-in gate for live-provider mode. Completion tests use a local
deterministic LLM/provider mock (LiteLLM-compatible where practical); an
external OpenRouter/backend connection is never required for an AR and must
not block completion. Offline modes and synthetic doubles remain default and
never touch the network.

## Dependencies and ownership

Dependencies: AR-1327 (OpenRouter adapter projections and parity), AR-1328
(per-user configuration and enrollment), and AR-1340 (attested namespace-bound
relay handoff). Owned paths: the execution path in
`asb-cli` (`execute_inner`, `ExecutionDefinition`), the agent process launcher,
credential resolution from the enrolled environment channel, the final CLI
egress enforcement hook, and the opt-in live-run flag. The runtime namespace
and child handoff are owned by AR-1340; this AR fails closed until that
capability is present. Branch:
`feature/ar-1329-live-provider-run-execution`. Worktree:
`agent-systems-benchmark-ar-1329-live-provider-run-execution`.

## Work sequence

1. Route `execute_inner` through the AR-1327 provider-aware launch projection
   so the constructed execution matches every requested provider, model,
   settings, and credential field.
2. Replace the digest-pinned runtime stub with a real agent process for the
   selected provider, keeping the digest-pinned mode available as the default
   offline fallback.
3. Resolve credentials only through the enrolled `OPENROUTER_API_KEY`
   environment channel and prove they never appear in argv, environment, logs,
   manifests, or errors.
4. Enforce the declared egress allowances explicitly; deny any outbound
   provider traffic unless the user passed the explicit live opt-in flag.
5. Add execution tests using the local provider mock: live opt-in path, offline
   default, missing credential, egress denial, agent failure propagation,
   cancellation, and secret non-disclosure. Remote-provider execution is
   optional supplementary evidence only.

## Acceptance criteria

A real agent runs only under explicit opt-in with a matching provider/model
projection; the offline and double modes never contact a provider; local mock
provider tests exercise the live path without external network access;
credentials flow only through the enrolled environment channel; egress outside
the declared allowances is denied; and all existing gates remain green.

## Evidence and completion

Record immutable commits, local-mock live/opt-in observations, offline test
fixtures, egress denial evidence, independent review, exact-head CI, and
post-merge verification. Any remote-provider observation is optional and must
remain outside the completion gate.
