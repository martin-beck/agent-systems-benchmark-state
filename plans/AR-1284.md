# AR-1284: Runtime-owned strict-replay lifecycle execution

## Outcome

Connect the merged AR-1282 authenticated replay transport to the actual ASB primary strict-replay
command and runtime-owned supervised lifecycle. This is an ASB capability AR; asb-tui consumes it
later and is explicitly out of scope.

## Dependencies and ownership

Dependencies: AR-1282, AR-1237, AR-1238, AR-1239. AR-1282 is the merged transport foundation;
AR-1260--AR-1281 are blocked historical evidence and must not be reused as implementation branches.
Owned paths: `crates/asb-runtime`, `crates/asb-replay`, `crates/asb-cli`, and focused integration
fixtures/tests for runtime-issued launch and replay lifecycle. Worktree:
`agent-systems-benchmark-ar-1284-strict-replay-lifecycle`; branch:
`feature/ar-1284-strict-replay-lifecycle`.

## Work sequence

1. Read the complete ASB development documentation and this AR before claiming. Verify exact
   protected-main ancestry includes AR-1282 and establish a clean isolated worktree.
2. Define the narrow runtime-issued handoff consumed by the primary strict-replay argument path;
   preserve opaque authority, generation/request binding, bounded deadlines, and fail-closed
   malformed/stale/duplicate handling.
3. Wire supervised cassette execution through the runtime-owned entrypoint. Do not synthesize
   relay handles, namespace readiness, supervisor commands, or credentials in the CLI.
4. Add positive and negative offline fixtures for child success, provider/descendant egress denial,
   cancellation, timeout, crash/restart cleanup, unrelated-process isolation, and no fallback.
5. Run focused tests and all full applicable gates. Review the exact cumulative diff independently,
   publish only from a clean signed+DCO tree, wait for exact-head CI, merge through the protected
   workflow, and verify all exact-main post-merge workflows.

## Acceptance and evidence

Completion requires a real primary command path using runtime-issued authority and supervised
lifecycle evidence. Compilation, parser tests, transport-only round trips, or an unqualified mock
does not establish completion. Preserve privacy, zero-runtime-download, bounded subprocess, and
offline-after-install contracts; split missing runtime or sandbox capability into a new AR rather
than weakening any gate.
