# AR-1190: Authenticated agent catalog control

Acceptance criteria:

- strict request/response schemas support refresh and read-only status;
- stable agent IDs, target constraints, package/digest/signature/provenance and capabilities are
  included, with explicit reasons for unavailable agents;
- authentication, authorization, protocol-version negotiation and runner-generation binding are
  verified before data is exposed;
- malformed, stale, unsigned, incompatible and incomplete catalogs fail closed;
- deterministic fixtures, negative tests and cross-version compatibility tests pass;
- exact-head review, signed DCO commit, CI and durable handoff evidence are complete.
