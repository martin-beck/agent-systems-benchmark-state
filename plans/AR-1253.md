# AR-1253: Provision pinned Python transport fixture runtime

## Outcome

Provide a reviewed, immutable Python runtime image for the AR-1251 MockAgents transport fixture.
The runtime must be executable through the approved isolated runner without host Python, ambient
site packages, credentials, or unpinned downloads.

## Scope and dependency

Depends on AR-1252. Own only the runtime image/provenance, runner wiring, and its qualification
fixtures. Do not implement MockAgents transport scenarios or modify asb-tui.

## Acceptance

- Runtime image is locally available by immutable digest with source, interpreter, package-lock,
  and image provenance recorded under `/srv/data/projects`.
- Runner launches it with `--network none`, one validated read-only artifact/fixture input mount,
  bounded CPU/memory/PIDs/time, dropped capabilities, and explicit cleanup.
- Positive Python runtime and fixture invocation tests pass; mismatched digest, symlink, ambient
  site, network, mount, timeout, and cleanup cases fail closed.
- Focused/full locked gates, signed DCO commit, independent review, exact-head CI, and post-merge
  verification pass before AR-1251 is reopened.
