# AR-0820: Publish verifiable installation artifacts

## Outcome

Provide native ASB runner/CLI and `asb-tui` bundles with enough authenticated metadata for deterministic platform selection and installation.

## Dependencies and ownership

Dependencies: AR-0701, AR-0801, AR-0804, AR-0812.
Owned paths: release bundle layout, installer manifest/schema, signatures, checksums, platform selection, SBOM/provenance links, and packaging tests.
Branch: `feature/verifiable-install-artifacts`. Worktree: `agent-systems-benchmark-install-artifacts`.

## Work sequence

1. Define a versioned, bounded release manifest that maps supported OS, architecture, libc, and minimum kernel/user-space requirements to immutable HTTPS artifacts.
2. Package the runner/CLI and separate TUI with licenses, completions, man pages, service templates, exact source revision, checksums, SBOM, and SLSA-style provenance without bundling credentials or host configuration.
3. Sign manifest and artifacts with a documented rotation/revocation policy; verify signatures and SHA-256 before extracting or executing any payload.
4. Make platform detection explainable and overrideable, but fail closed for ambiguous libc, unsupported architecture, missing CPU features, invalid paths, downgrade, manifest expiry, unknown keys, or version skew.
5. Produce reproducible x86_64/aarch64 glibc/musl artifacts only for native cells actually proven, plus offline bundles and mirrors with the same verification chain.

## Acceptance criteria

Every published bundle is content-addressed, signed, reproducibly attributable, relocatable, and selected only for a proven platform; runner and TUI versions/protocol ranges agree; corrupt, swapped, expired, downgraded, or unsupported inputs fail before mutation; and unsupported combinations are named rather than guessed.

## Evidence and completion

Record exact build images/tools/refs, two-build comparison, artifact/signature/SBOM/provenance digests, native smoke runs, negative fixtures, independent supply-chain review, exact-head CI, and release-host checks.
