# AR-0856: Coordinate OpenJiuwen and WorkBuddy agent support

## Outcome

Coordinate two independent, evidence-gated agent-support series without owning product code.

## Dependency graph

- OpenJiuwen: AR-0857 provenance -> AR-0858 adapter -> AR-0859 live -> AR-0860 replay ->
  AR-0861 parity/support matrix -> AR-0862 independent qualification/docs.
- WorkBuddy: AR-0863 provenance -> AR-0864 adapter -> AR-0865 live -> AR-0866 replay ->
  AR-0867 parity/support matrix -> AR-0868 independent qualification/docs.
- AR-0856 depends directly on AR-0862 and AR-0868 and completes only when both are done.

The discovery children depend on AR-0101/0102/0103, AR-0310/0315, AR-0317, AR-0503, and the
blocked AR-0855 serialization prerequisite. Shared `lib.rs`, Cargo/lock, provider-parity, README,
architecture, and platform-matrix paths are mutated only under explicit serialized fences.

## Acceptance and evidence limits

Both agents independently require official immutable source, executable/package digest, complete
dependency and license closure, bounded contract/capabilities, credential-free loopback live editing,
tool/usage/cancellation/network-denial evidence, sealed strict replay, provider parity, platform
support limits, privacy/security negatives, independent review, exact-head CI, and post-merge gates.
No mock, parser fixture, source inspection, build, version string, cross-build, replay-only result, or
private credential qualifies either agent. If evidence is unavailable, keep the responsible child
blocked and, when a materially distinct remediation is needed, add a dependency-linked blocked child;
the sibling series may continue but the umbrella remains planned.
