# AR-0816: Qualify cross-platform remote control

## Outcome

Prove that frontend and runner can differ in architecture, distribution, library stack, and compatible release version.

## Dependencies and ownership

Dependencies: AR-0702, AR-0815, AR-0819.
Owned paths: remote compatibility matrix, native deployment harnesses, golden wire fixtures, upgrade/skew tests, and evidence.
Branch: `test/remote-interoperability`. Worktree: `agent-systems-benchmark-remote-interoperability`.

## Work sequence

1. Test native x86_64 controller/runner combinations plus x86_64-to-QEMU-AArch64 and reverse
   protocol roles on mainstream Linux and available openEuler userspace combinations. Native
   ARM64 controller/runner tests are optional future qualification.
2. Verify language-independent JSON/schema semantics, fixed numeric/time units, Unicode, path opacity, platform capability ownership, TLS/certificate validation, and byte-identical golden messages.
3. Exercise the supported frontend/runner version-skew window, rolling runner upgrade, reconnect after upgrade, unsupported major versions, unknown fields, and downgrade resistance.
4. Run WAN-like latency, loss, bandwidth, MTU, IPv4/IPv6, DNS/IP certificate, NAT/SSH-tunnel documentation, suspend/resume, and long-disconnect tests without treating tunnels as automatic trust.
5. Confirm controller platform assumptions never leak into runner scheduling, measurement, artifact paths, binaries, or support claims.

## Acceptance criteria

Every claimed architecture/distribution direction completes configure/launch/detach/reconnect/status/cancel/history flows; protocol data is platform-neutral and bounded; incompatible versions fail before mutation; emulated evidence is labeled and never used for native performance claims; runner measurements remain attributable to the runner; unsupported combinations are listed explicitly; and missing native ARM64 capacity cannot block completion.

## Evidence and completion

Record exact OS/kernel/architecture/package/ref/certificate matrices, wire digests, fault results, immutable commits, reviews, CI/native run IDs, performance overhead, and evidence gaps.
