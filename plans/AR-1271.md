# AR-1271: Dependency-neutral cassette operation contract

## Outcome

Define a bounded shared cassette request/response operation contract that runtime can transport and
supervise without importing `asb-replay` implementation types, while CLI adapters perform strict
validation and decoding.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1270 is blocked design evidence and its unmerged branch
is not an input. Owned paths: `asb-core` operation schema/types, runtime service transport, CLI
adapter, and positive/negative integration fixtures. Branch:
`feature/ar-1271-cassette-operation-contract`. Worktree:
`agent-systems-benchmark-ar-1271-cassette-operation`.

## Work sequence

1. Specify a versioned bounded request/response envelope with generation, cassette, route, method,
   body-size and digest identities; reject unknown, malformed, stale, duplicate, credential-bearing,
   and fallback/provider fields.
2. Implement runtime service transport using only the shared contract and exact-once operation
   handles. Keep runtime independent of CLI/agent/replay crates and offline after install.
3. Add CLI adapter decoding into strict replay types and integrate actual replay dispatch. Prove one
   real cassette request/response, provider/descendant egress denial, no-live-fallback, cancellation,
   restart, timeout/crash reaping, and cleanup/no-leak behavior.
4. Run full locked gates, schema/policy/privacy/signature/DCO, independent review, exact-head CI,
   signed merge, and post-merge assurance.

## Acceptance criteria

Runtime transports only the dependency-neutral operation contract; CLI cannot inject launch
authority or provider fallback. The actual replay command performs real bounded cassette traffic and
all lifecycle/egress failure paths are fail-closed and evidenced.
