# AR-1012: Qualify TUI quality and isolation

## Outcome

Prove that the Ratatui/Crossterm frontend is reliable, accessible, portable, and operationally isolated from benchmark measurements.

## Dependencies and ownership

Dependencies: AR-1010, AR-1011, AR-0807, AR-0873.
Repository: `martin-beck/asb-tui`. Owned paths: TUI qualification tests, CI capture fixtures,
terminal matrix evidence, performance/isolation probes, and support documentation updates.
Branch: test/tui-quality-assurance. Worktree: agent-systems-benchmark-asb-tui-quality-assurance.

## Work sequence

1. Test deterministic frames and escape streams with Ratatui TestBackend, including 1x1, compact, standard, wide, resize storms, Unicode width, combining marks, and malformed input.
2. Exercise normal exit, panic, signal, suspend/resume, SSH loss, tmux/screen detach, reconnect, cancellation, and stale-control-event paths.
3. Measure attached versus detached CPU, memory, I/O, and benchmark timing overhead with a declared budget; fail if the UI changes workload results.
4. Run keyboard-only, contrast, focus, NO_COLOR, plain-output, and screen-reader-oriented checks on supported terminal classes.
5. Generate privacy-safe screenshots/text captures from synthetic CI executions and link them from the workflow documentation.

## Acceptance criteria

All declared terminal classes restore state correctly; no panic, stale cell, event loss, or unbounded redraw is observed; accessibility fallbacks are usable; UI overhead is within the declared budget; captures are reproducible and secret-free; and unsupported terminal features are reported rather than guessed.

## Evidence

Publish exact terminal/version matrix, snapshot and escape-stream artifacts, fault and accessibility results, overhead measurements, sanitized CI screenshots, immutable review, exact-head CI, and post-merge verification.
