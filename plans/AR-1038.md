# AR-1038: Preserve coverage sinks in sanitized CLI child tests

## Outcome

Keep ASB's environment-cleared CLI contract tests isolated while forwarding the exact test-owned
LLVM coverage output path so instrumented child processes cannot dirty the source checkout.

## Dependencies and ownership

Dependency: AR-1023. Repository: `martin-beck/agent-systems-benchmark` only. Owned paths are the
capability CLI test harness and focused coverage/isolation regressions. No production environment
inheritance, TUI behavior, renderer, Ratatui, Crossterm or standalone frontend path is owned.
Branch: `test/capability-coverage-sink`. Worktree:
`agent-systems-benchmark-capability-coverage-sink`.

## Work sequence

1. Centralize capability-contract child command construction and retain `env_clear()`.
2. When and only when the parent supplies a valid absolute `LLVM_PROFILE_FILE` test sink, forward
   that exact value to every canonical and negative child. Permit a resolved external sink or the
   exact cargo-llvm-cov sink beneath the ignored workspace `target/` subtree. Reject other
   checkout paths, traversal, symlinked ancestors, shared filenames, relative, empty, oversized or
   control-character values; inherit no other ambient variable.
3. Run focused tests normally and under workspace llvm-cov, proving all six current child paths
   write beneath the declared external coverage root or ignored workspace `target/` root and no
   root-level `default_*.profraw` appears anywhere in the product checkout.
4. Exercise absent and malformed coverage variables, child failure and parallel test execution.

## Acceptance criteria

Capability CLI tests preserve their closed environment; coverage-enabled children emit only to the
validated test-owned external sink or the absolute ignored workspace `target/` sink supplied by
cargo-llvm-cov; normal execution needs no coverage variable; malformed values fail closed without
source-tree artifacts; and production ASB behavior is unchanged.

## Evidence

Record focused and workspace coverage runs, exact before/after artifact scans, environment-negative
tests, full applicable ASB quality/privacy gates, independent review, exact-head CI and post-merge
verification.
