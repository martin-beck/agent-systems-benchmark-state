# AR-1242: Enforce signed protected-main admission

## Outcome

Ensure every future protected-main update is an SSH-signed, DCO-bearing integration commit with
the reviewed topic tree and exact approved parents. Published unsigned historical merges remain
immutable and are documented as historical limitations.

## Dependencies and ownership

Dependencies: AR-0003 and AR-0897. Owned paths are protected-branch integration tooling,
repository settings/documentation, policy fixtures, and recovery evidence. Do not modify
unrelated product capability code or weaken existing gates.

## Work sequence

1. Audit current branch-protection and merge-mode settings, workflow triggers, and the exact
   admission path that allowed merges `1c07e907`, `a7a64bcc`, and `606375f`.
2. Implement a fail-closed admission check or equivalent protected integration control that
   rejects missing SSH signatures, missing/mismatched DCO, stale base, wrong head, and wrong tree
   before publication. Disable incompatible web merge modes where repository controls permit it.
3. Provide a documented local signed `--no-ff --gpg-sign/SSH-sign --signoff` integration command
   using immutable approved PR heads and exact `--force-with-lease` publication.
4. Add bounded negative and positive fixtures for unsigned GitHub merges, non-DCO commits,
   wrong-head/tree, stale-base, valid signed local merges, and forward-only recovery.
5. Run focused and full applicable gates, obtain independent exact-head review, publish only from
   a clean signed-DCO tree, wait for exact-head CI, merge through the protected path, and verify
   the resulting main signature/DCO/tree plus every post-merge workflow.

## Acceptance criteria

Current main has fresh green exact-main evidence; future admission rejects unsigned/non-DCO web
merges before publication; reviewed topic tree and exact parents are preserved; negative fixtures
prove fail-closed behavior; published history is not rewritten; recovery is documented and
reproducible; privacy, formal, signature, DCO, and post-merge evidence are durable.
