# AR-1214: LLM response record/replay tutorial

Create the tutorial for recording bounded, privacy-safe LLM API response cassettes and replaying
them offline. Explain redaction, provenance, deterministic selection, malformed-record rejection,
and the explicit guarantee that replay does not fall back to a provider.

CI parses and validates the command sequence, cassette schema, digest/provenance references, and
network-denial assertions. It uses synthetic fixtures only and never records, replays, or contacts
an LLM service.
