# AR-0813: Add secure remote control transport

## Outcome

Expose the AR-0803 message contract over an explicitly enabled, secure IP transport for a separate controller machine.

## Dependencies and ownership

Dependencies: AR-0702, AR-0803, AR-0902.
Owned paths: remote listener/client transport, TLS configuration, framing/ALPN, network limits, and protocol/fault tests.
Branch: `feature/remote-control-transport`. Worktree: `agent-systems-benchmark-remote-control-transport`.

## Work sequence

1. Reuse the same bounded JSON-RPC 2.0 message/schema model as local IPC, framed over TLS 1.3 TCP with an ASB-specific ALPN and explicit version negotiation; use transport-independent causal IDs, cursors, limits, and errors.
2. Keep remote listening disabled by default. Require an explicit IP/interface and port, validate wildcard/public binds separately, expose effective addresses in doctor output, and never infer a network bind from SSH/TMUX/STY or frontend location.
3. Enforce mutual authentication before application data, modern cipher suites, certificate name/IP validation, bounded handshakes/frames/connections/streams, backpressure, keepalive, idle deadlines, rate limiting, and graceful drain.
4. Resume event subscriptions from durable revisions after disconnect without replay gaps, unbounded buffers, or duplicate mutations; the runner continues with zero connected clients.
5. Test malformed/truncated/oversized frames, slowloris, half-open sockets, packet loss/reorder, reconnect storms, protocol skew, invalid certificates, downgrade attempts, port reuse, address changes, IPv4/IPv6, and network partitions.

## Acceptance criteria

No unauthenticated or plaintext remote control is possible; no network listener exists unless explicitly configured; bind and advertised addresses cannot be confused; all limits negotiate fail-closed; disconnect never cancels or pauses a run; reconnect converges to durable runner truth; transport overhead is bounded; and local Unix-socket operation remains available and behaviorally equivalent.

## Evidence and completion

Record threat model, wire fixtures, TLS/tool pins, packet/fault tests, immutable commits, independent security review, exact-head CI, native platform runs, and unsupported network environments.
