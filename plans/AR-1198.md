# AR-1198: Canonical authenticated agent-catalog digest

Repository: `martin-beck/agent-systems-benchmark`.

Dependencies: AR-1190. The standalone `martin-beck/asb-tui` adapter consumes
this identity through AR-1195; it must independently reproduce the vectors.

Owned paths: `crates/asb-control/src/catalog.rs`, the v1.4 catalog fixture and
tests, and `docs/AGENT_CATALOG_DIGEST.md`. Do not modify any TUI, renderer,
Ratatui, Crossterm, frontend application, provider implementation or private
runtime state.

## Implementation contract

Hash the typed v1.4 `AgentCatalog` snapshot after fail-closed validation. Remove
only `catalog_sha256`; recursively sort JSON object keys by UTF-8 byte order;
retain arrays in their validated protocol order; emit compact UTF-8 JSON with
the pinned serde JSON escaping and typed integer representation; hash with
SHA-256 and encode lowercase hexadecimal. Validate the supplied digest equals
the recomputed value before publication or frontend use. Never canonicalize a
malformed object as a repair operation.

## Required evidence

- normative algorithm document with canonical bytes and at least two complete
  vectors (including the checked-in v1.4 response);
- positive vector and negative tests for digest mismatch, object member order,
  self-field exclusion, array reorder, duplicate/unsorted IDs and capabilities,
  target mismatch, unknown fields and malformed digests;
- schema/Rust fixture conformance and full ASB quality gates on the exact PR
  head, independent immutable-head review, protected merge and post-merge
  assurance;
- asb-tui AR-1195 records matching bytes/digest and rejects any mismatch before
  selection, install, comparison or launch.

Completion is not claimed by a valid SHA-256 shape alone: the exact typed
content identity and cross-repository vector must match.
