# AR-1213: Benchmark run and shared-agent configuration tutorials

Create two linked tutorials: perform a benchmark run from a verified configuration, and extend
the configured agent set while applying the same explicit configuration to every selected agent.
Cover selection, workload/measurement identity, run status, bounded artifacts, and atomic failure
when one target is incompatible.

CI validates the complete command sequences and fixture/result schemas without starting a benchmark,
provider, subprocess, or network connection. Examples must use synthetic IDs and redacted paths.
