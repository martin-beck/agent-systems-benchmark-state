# AR-1246: Make protected-main DCO admission durable

## Outcome

Fix the repeated post-merge failure where GitHub-generated protected-main merge commits lack
individual DCO trailers, while retaining strict DCO/signature checks for every reviewed topic
commit and requiring the authenticated web-flow merge attestation.

## Acceptance

- In protected-main mode, validate DCO and SSH signatures for all topic commits.
- Validate the GitHub merge commit through the pinned web-flow attestation and exact topology/tree;
  do not require a redundant trailer on the service-generated merge commit.
- Keep ssh-only/PR validation strict for every commit and reject unknown synthetic merges.
- Add regression tests for PR-192/PR-194-style merges and future unknown merges.
- Run full quality gates and post-merge workflows; do not rewrite published history.
