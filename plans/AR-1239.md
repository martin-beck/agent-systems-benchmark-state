# AR-1239: Signed supervisor and sidecar runtime bundle

## Outcome

Provide an installable, offline-verifiable runtime bundle containing the exact loopback supervisor
and sidecar payloads required by AR-1238.

## Dependencies and ownership

Dependency: AR-1236. Repository: `martin-beck/agent-systems-benchmark`. Own only asb-bundle
manifest/payload wiring, signing, verification, and bundle-level tests. Runtime launch integration
remains owned by AR-1238.

## Acceptance

- Reproducibly build the supervisor and sidecar for each supported target.
- Package both as regular, non-symlink relative artifacts with safe executable permissions and
  explicit supervisor/sidecar roles.
- Extend the canonical manifest/SBOM inventory with exact paths, sizes, SHA-256 digests, target
  metadata, and content digest coverage.
- Produce and verify a detached signature over the canonical manifest bytes using the
  `asb-runtime-bundle-v1` namespace and the configured offline trust root.
- Reject tampered, missing, duplicate, extra, symlinked, wrong-mode, wrong-target, or unsigned
  payloads; expose verified payload paths and digests to runtime consumers.
- Run locked workspace, format, clippy, rustdoc, signature/DCO, exact-head CI, and native bundle
  verification gates. Provide fixtures for AR-1238's Bubblewrap cassette, egress-denial, teardown,
  and unrelated-process tests.
