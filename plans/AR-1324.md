# AR-1324 authenticated credential-helper control contract

## Outcome

Expose a negotiated, runner-owned one-shot helper operation that returns only
credential-free enrollment metadata and typed lifecycle outcomes.

## Scope

- versioned request/response schema and exact JSON fixtures;
- allowlisted helper identity and private runtime registration;
- sealed helper execution with bounded output, timeout, cancellation and
  process cleanup;
- runner/generation/idempotency fencing and restart behavior;
- hostile path, environment, stdout, raw-key and stale-result tests;
- standalone TUI compatibility evidence for AR-1323.

## Acceptance

- no arbitrary command/path or raw secret can cross the control boundary;
- helper success returns provider, endpoint digest and locator digest only;
- failure, cancellation, timeout and unavailable states are explicit;
- locked tests, schemas, Clippy, DCO, hosted gates and live TUI projection pass.
