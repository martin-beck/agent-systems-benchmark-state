# AR-0870: Add TUI multi-agent provider selection

## Outcome

Let users select several configured agents and apply one compatible preconfigured provider profile to all selected agents from searchable TUI lists.

## Dependencies and ownership

Dependencies: AR-0804, AR-0805, AR-0844, AR-0869.
Owned paths: TUI agent/provider selectors, review screen, help, text snapshots, interaction tests, and focused documentation.
Branch: `feature/tui-multi-agent-provider-selection`. Worktree: `agent-systems-benchmark-tui-multi-agent-provider-selection`.

## Work sequence

1. Render searchable multi-select agents and single-select shared provider-profile lists only from freshly negotiated runner capabilities.
2. Recompute compatibility as agents change, preserve valid choices, explain disabled choices, and require explicit review before plan creation.
3. Display safe profile labels, provider/model identity, live or replay availability, credential reference kind, and effective settings without secret values.
4. Provide keyboard-only selection, select-all/clear, filter, help, backtracking, narrow-terminal and plain-text behavior.
5. Test stale catalogs, reconnect, incompatible agents, no common provider, resize, no-color, malformed server data, and parity with AR-0869 CLI plans.

## Acceptance criteria

A beginner can choose multiple agents and exactly one common preconfigured provider without memorizing identifiers; every enabled choice is runner-advertised and compatible; the review matches the content-pinned plan; and equivalent CLI and TUI selections produce equivalent normalized settings.

## Evidence and completion

Record public interaction fixtures, accessible text snapshots, CI-generated screenshots, negative tests, immutable review, exact-head CI, and post-merge verification.
