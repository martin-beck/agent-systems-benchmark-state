# AR-1207: Deterministic LLM-double CI coverage of the integrated workflow

## Outcome

Wire the deterministic LLM double (`tools/llm-double-spike`, AR-0890) into credential-free CI so
the full record/replay/benchmark journey is exercised on every PR without a paid key.

## Dependencies and ownership

Dependencies: AR-0890 (LLM-double integration), AR-1203 (replay-mode run/sweep), AR-1206
(integrated docs). Repository: `martin-beck/agent-systems-benchmark` only. Owned paths are CI
workflow jobs, the `tools/llm-double-spike` invocation contract (AR-1251/1253 pinned runner),
product integration tests reusing the double as a loopback provider, and hostile lifecycle tests
(startup fail-closed, network denial, provenance). Branch: `feature/llm-double-ci`. Worktree:
`agent-systems-benchmark-llm-double-ci`.

## Work sequence

1. Adopt the pinned isolated double as the credential-free loopback provider for the
   record/replay/benchmark integration tests (AR-1204 journeys, replay-mode sweeps).
2. Prove fail-closed startup, `--network none`, bounded artifact bind, and provenance verification
   in CI.
3. Keep the double strictly separate from replay evidence; synthetic output cannot convert into
   cassette/replay or live evidence.

## Acceptance criteria

Every PR runs the integrated journey against the double without credentials or external network;
hostile and missing-artifact cases fail the job; the double never masquerades as replay or live
evidence.

## Evidence

Green PR workflow, fault fixtures, provenance checks, exact-head CI.
