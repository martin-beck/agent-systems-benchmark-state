# AR-0313: Configure one provider for all agents

## Outcome

Provide one CLI/config option that applies a chosen provider profile atomically to all selected compatible agents.

## Dependencies and ownership

Dependencies: AR-0311, AR-0312.
Owned paths: run-plan configuration, all-agent provider preflight, CLI/API surfaces, and documentation.
Branch: `feature/all-agents-provider`. Worktree: `agent-systems-benchmark-all-agents-provider`.

## Work sequence

1. Add a versioned `all_agents_provider` selection while retaining explicit per-agent overrides only when requested.
2. Resolve the complete selected agent set and negotiate every adapter before creating any run intention.
3. Display a deterministic effective-settings and unsupported-field report without credentials.
4. Reject mixed, partial, stale, ambiguous, or lossy resolution unless the user explicitly chose per-agent profiles instead.
5. Test interactive and noninteractive use, cancellation before launch, concurrent plans, recovery, and stable serialization.

## Acceptance criteria

One option configures every selected supported agent; any incompatible agent prevents the whole plan from starting and identifies the exact unsupported fields; effective profile identities are identical in all run manifests; noninteractive invocations never prompt or hang; and retries/recovery cannot produce a partly changed agent set.

## Evidence and completion

Record exact normalized/effective identities, negative matrices, immutable commits, reviews, CI, post-merge checks, and UI/CLI limitations.
