# AR-1441 — First-class install and bootstrap

## Scope

Make a clean install of the ASB CLI/runtime bundle self-discovering and
reversible. Ship a verified install/upgrade path that detects the supported
platform, creates only private configuration/state roots, and starts the CLI
first-run flow without requiring users to find documentation or type internal
paths. Preserve signed artifacts, rollback, credential isolation, and
fail-closed behavior when a bundle or platform is unsupported. The optional
asb-tui and cross-repository journey remain in AR-0823/AR-1444 and are not
modified here.

## Dependencies

Depends on AR-0821 and AR-0822. The existing installer ARs own the artifact and
rollback primitives; this AR owns the ASB CLI user-facing entry point and
clean-install acceptance journey. AR-0823 remains a separate UI/cross-project
audit.

## Acceptance

- A clean supported host can install current ASB CLI/runtime bundles and launch
  the guided flow with one documented command and no manual path editing.
- Unsupported, unsigned, partial, and interrupted installs stop before making
  an unusable default and expose a short actionable recovery choice.
- Upgrade, rollback, uninstall, private-state permissions, and secret absence
  are tested from a disposable environment.
- The output is machine-readable and does not duplicate provider or model
  catalogs.

## Required evidence

Signed+DCO PR, exact-head hosted gates, clean disposable install/upgrade/
rollback transcript, and post-merge verification on the supported matrix.
