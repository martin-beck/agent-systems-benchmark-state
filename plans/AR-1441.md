# AR-1441 — First-class install and bootstrap

## Scope

Make a clean install of ASB self-discovering and reversible. Ship a verified
install/upgrade path that detects the supported platform, installs the ASB CLI
and optional asb-tui bundle, creates only private configuration/state roots,
and starts the first-run flow without requiring users to find documentation or
type internal paths. Preserve signed artifacts, rollback, credential isolation,
and fail-closed behavior when a bundle or platform is unsupported.

## Dependencies

Depends on AR-0821, AR-0822, and AR-0823. The existing installer ARs own the
artifact and rollback primitives; this AR owns their single user-facing entry
point and clean-install acceptance journey.

## Acceptance

- A clean supported host can install current ASB and launch the guided flow
  with one documented command and no manual path editing.
- Unsupported, unsigned, partial, and interrupted installs stop before making
  an unusable default and expose a short actionable recovery choice.
- Upgrade, rollback, uninstall, private-state permissions, and secret absence
  are tested from a disposable environment.
- The output is machine-readable for TUI consumption and does not duplicate
  provider or model catalogs.

## Required evidence

Signed+DCO PR, exact-head hosted gates, clean disposable install/upgrade/
rollback transcript, and post-merge verification on the supported matrix.
