# AR-1256: Execute bundled MockAgents transport in isolation

## Outcome

Run the real pinned MockAgents executable and transport fixture together inside a digest-pinned
Python/QEMU runtime, producing genuine bounded lifecycle and network-denial evidence.

## Dependencies and ownership

Dependencies: AR-1252, AR-1253. Own only bundled transport fixture, isolated runner integration,
QEMU arm64 execution, and evidence. Do not modify asb-tui or rewrite prior partial AR history.

## Acceptance

- One content-addressed read-only bundle contains fixture and exact amd64/arm64 MockAgents files,
  with closed source/tag/commit/license/checksum/platform provenance.
- In-container execution parses real MockAgents transport events and proves malformed/oversized
  rejection, tool-result ordering, bounded backpressure/cancellation, descendant cleanup, and
  repeat-clean-state. A real non-loopback connection attempt fails under `--network none`.
- Arm64 runs under a digest-pinned QEMU user-mode runtime; mutable images, host Python, extra
  mounts, credentials, fallback egress, and unbounded evidence fail closed.
- Signed DCO, focused/full gates, independent review, exact-head CI, protected merge and post-merge
  verification pass before release.
