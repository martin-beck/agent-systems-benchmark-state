# AR-1211: Initial ASB setup and first agent connection tutorial

Create the first-time-user tutorial for initializing ASB, adding the first coding agent, and
configuring its agent connection/provider reference. Show safe secret-reference handling and the
expected verification checkpoints without embedding keys or requiring a live provider.

All examples use deterministic placeholders and the AR-1210 syntax contract. CI parses every step,
checks command/options/order and referenced files, and validates expected structured output without
executing any command.

Acceptance requires a clean-home, no-network syntax fixture covering initialization, first-agent
registration, connection configuration, reconfiguration, and safe failure paths.
