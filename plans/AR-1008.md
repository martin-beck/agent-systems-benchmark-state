# AR-1008: Integrate Agent Workflow Quality in shadow mode

## Outcome

Agent Systems Benchmark and its state repository run immutable AWQ v0.1.0 as non-authoritative additive evidence.

## Scope

- Add deterministic policy and lock files appropriate to each repository.
- Add a pinned GitHub Actions shadow workflow that cannot replace or suppress existing checks.
- Preserve all Rust, Python, shell, documentation, schema, privacy, formal, fault and coordination gates.
- Exclude every handoffctl implementation or semantic change.

## Acceptance

- Pins use the exact AWQ v0.1.0 source commit and registry digest.
- Local doctor/check output is recorded only as bounded summary evidence.
- Both repositories remain clean, coordinated and pass existing mandatory validation.
- Product publication uses a reviewed PR; state updates remain consistent under live doctor.
