# AR-1212: Agent benchmark-readiness tutorial

Create the tutorial that checks whether a configured agent can be used for benchmarking under the
current ASB configuration. Explain capability, platform, provider, credential-reference, workload,
and budget refusal results and the difference between readiness checking and performing a run.

The CI contract validates command syntax, option compatibility, ordering, fixture schemas, and
stable refusal/result fields offline. It must not launch the agent, contact an LLM, or claim a live
qualification from syntax evidence.
