# AR-1216: ASB tutorial freshness CI and documentation qualification

Wire every ASB tutorial into a single CI freshness gate. The gate must discover tutorial files and
steps, validate them against current command metadata and schemas, reject stale options/order,
ensure referenced tutorials and expected outputs remain valid, and prove the no-execution/no-network
boundary.

Acceptance requires mutation coverage for renamed/removed commands and options, a clean-home
offline run, deterministic diagnostics, and documentation checks that do not require credentials,
providers, an LLM, or benchmark artifacts from a real run. Record exact command metadata and CI
identities after integration.
