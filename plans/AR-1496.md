# AR-1496 — Runtime-owned provider capture and control activation

## Scope

Complete the missing successor to blocked AR-1160. Connect the authenticated
provider capture seam to the real ASB control/campaign path so each selected
agent × workload tuple receives durable cassette evidence, restart/reconcile
behavior, and a verified offline-default activation. The mandatory qualification
path is the runtime-owned deterministic local/mock provider; external OpenRouter
reachability remains optional and non-gating.

The implementation must use the existing runtime authority, replay service,
campaign, and control contracts. It must not fabricate live authority, accept
caller-supplied credentials, persist raw keys/prompts/responses, or bypass
NetworkPolicy/egress and cancellation gates.

## Dependencies

Depends on AR-1151, AR-1330, AR-1433, AR-1447, AR-1450 and AR-1455. These provide
strict replay, sealed capture primitives, local authority, campaign qualification,
and the runtime-owned guided entrypoint. AR-1160 remains historical and blocked.

## Acceptance

- The real control campaign invokes runtime-owned capture for every selected
  tuple instead of manually mutating aggregate state.
- Each tuple records bounded identity/digest/status evidence and reconciles
  interrupted capture without repeating provider effects.
- Offline activation requires complete, compatible sealed evidence and runs
  strictly without provider contact; missing, stale, mixed, malformed and
  duplicate tuples fail closed.
- Control/API and CLI/TUI projections expose the same generation-fenced status,
  progress, cancellation, and readiness semantics.
- Deterministic local/mock tests cover positive capture, restart, cancellation,
  timeout, malformed response, no-fallback, secret non-disclosure, and full
  offline replay. No live key or external response is required for completion.
- The local/mock development profile must not block when authentication,
  signature validation or key management is absent; it uses the generated
  development identity and labels the resulting evidence accordingly.

## Publication evidence

Focused and full locked tests, clippy/fmt/docs, privacy and coverage gates,
independent review, signed+DCO exact-head PR, all required hosted checks, and
seven exact-main post-merge workflows.
