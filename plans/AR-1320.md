# AR-1320 persisted authenticated agent release index

## Outcome

Make the agent catalog source durable, authenticated, restart-stable, and
eligible to mark an entry available only after a complete verified closure.

## Scope

ASB control backend, bounded signed release-index fixture/source, persistence,
generation fencing, schema/fixture tests, and live TUI compatibility evidence.

## Design obligations

1. Read only a bounded local signed release index; reject mutable paths,
   unsigned or tampered metadata, duplicate IDs, target mismatch, and partial
   closure claims.
2. Persist the validated public snapshot and monotonic generation atomically in
   the runner catalog; restart must preserve the exact digest and generation.
3. Make Status read-only and Refresh idempotent, generation-fenced, and
   rollback-safe. `refreshed` remains response-only and excluded from identity.
4. Keep incomplete entries visible but unavailable; only complete package,
   signer, SBOM, license, source, target, and capability evidence may select.
5. Prove exact ASB-to-asb-tui wizard projection and fail closed on stale or
   unsupported release-index revisions.

## Acceptance evidence

- signed release-index fixtures and hostile mutation tests;
- restart, refresh, generation, digest, and atomic persistence tests;
- locked workspace/clippy/schema tests and exact-head hosted gates;
- post-merge live control call consumed by the standalone TUI wizard.
