# AR-1036: Publish the measurement catalog control contract

## Outcome

Expose ASB's versioned measurement catalog to independent frontends through a bounded, deterministic
and privacy-safe control operation.

## Dependencies and ownership

Dependencies: AR-1013 and AR-1023. Repository: `martin-beck/agent-systems-benchmark` only. Owned
paths are control request/response types, backend dispatch, capability advertisement, generated JSON
Schema, bounded public fixtures, CLI/protocol parity tests and contract documentation. No Ratatui,
Crossterm, renderer, screen, widget, navigation, terminal lifecycle or frontend state path is owned.
Branch: `feature/measurement-catalog-control`. Worktree:
`agent-systems-benchmark-measurement-catalog-control`.

## Work sequence

1. Add one closed, versioned catalog request/response method that returns the AR-1013 semantic groups
   and measurements, stable IDs, descriptions, units, aggregation, overhead, availability,
   live/replay status, platform support, evidence limits and a content digest.
2. Bind the capability response to the implemented operation and fail closed for protocol/version,
   unknown-field, duplicate-ID, invalid-unit, unavailable-source and oversized-result drift.
3. Define deterministic ordering, explicit pagination or a documented hard maximum, stable error
   codes, freshness/provenance fields and exact request/result byte limits.
4. Generate schema and positive/negative fixtures from the Rust model; run the pinned standalone
   consumer's existing parser as a read-only conformance proof against exact output without
   importing ASB workspace code. Any parser or frontend fixture change belongs to AR-1025 or
   AR-1014 in `martin-beck/asb-tui`, never to this AR.
5. Verify empty, maximal, unsupported, mixed live/replay, platform-skew and privacy-sensitive
   catalogs, plus schema/version skew and digest mismatch.

## Acceptance criteria

The standalone TUI can obtain every selectable measurement and semantic group without reading ASB
files or linking its workspace; every advertised field maps to authoritative ASB catalog state; the
response is bounded, deterministic and privacy-safe; unsupported and stale values remain explicit;
and ASB contains no presentation or interaction behavior.

## Evidence

Record exact schema/fixture hashes, cross-repository parser conformance, size and malformed-input
tests, capability parity, full ASB quality/security/privacy gates, independent protocol review,
exact-head CI and post-merge verification.
