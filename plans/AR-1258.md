# AR-1258: Provision Docker binfmt/QEMU capability

## Outcome

Provision and verify the approved Docker binfmt/QEMU registration required for ASB multiarch
qualification, with immutable image/provenance checks, bounded smoke tests, and rollback-safe
cleanup. Host-local QEMU outside Docker is not evidence.

## Dependencies and ownership

No blocked product dependencies. Owned paths: `tools/quality/`, `docs/DOCKER_QEMU.md`, and
sanitized capability evidence under the coordination state. Do not modify provider or asb-tui
source, Docker daemon policy, or persistent host configuration without explicit approved sudo.

## Acceptance

- Approved container workflow verifies binfmt registrations, QEMU interpreter identity, Docker
  architecture execution, and exact immutable image digest.
- Positive and negative checks cover missing registration, wrong interpreter, mutable tags,
  architecture mismatch, signature/license/provenance drift, timeout, and rollback cleanup.
- No credentials, host identity, private paths, raw logs, or mutable image claims are retained.
- If approved privilege or registration is unavailable, release blocked with exact sanitized
  evidence; never substitute host QEMU or silently pass.
