# AR-0892: Compare LLM test and inference evidence modes

## Outcome

Publish reproducible strengths, blind spots, overhead and saturation boundaries for the selected mock, cassette replay, qualified local inference and an explicitly provisioned remote-live control.

## Dependencies and ownership

Depends on AR-0890 and AR-0891. Own comparison matrix, public scenario mapping, experiment
manifests, independent-grader selection and isolation contract, analysis/report
output and limitations. Do not combine evidence classes in scoring. Branch
`test/llm-mode-comparative-evidence`; worktree
`agent-systems-benchmark-llm-mode-comparative-evidence`.

## Work sequence

1. Map identical public protocol/tool/failure scenarios where applicable; record unsupported cases without substitution.
2. Pre-register denominators for determinism, adapter coverage, TTFT/cadence, throughput, errors/cancellation, harness CPU/memory/queue delay and external cost.
3. Run repeated randomized-order pinned trials with independent warm-up/model/server/remote controls and separate mock/replay saturation telemetry.
4. Preserve synthetic, strict-replay, local-live and remote-live origins; compare harness behavior only where valid and never infer fresh model quality from mock/replay.
5. For quality comparisons claiming independent grading, select a distinct proven
   grader provider/model profile, credential reference, process state and network
   authorization. Record grader artifact/profile and evidence-class provenance.
6. Reject candidate/grader identity overlap, same local engine/model self-grading,
   synthetic or replay score promotion, unavailable-grader fallback and missing
   grader provenance. Publish hostile rejection evidence and one independently
   provisioned grading artifact for each independence claim.
7. Test swapped labels, missing manifests, overload, partial runs, unsupported
   capabilities and pooled denominators.
8. Publish machine-readable evidence, uncertainty and limits; support-catalog
   changes remain separately owned.

## Acceptance criteria

All modes have exact provenance/separate denominators; invalid pooling fails;
capacity and unsupported cases are visible; local/live variability has
trials/uncertainty; mock/replay determinism makes no OS claim; an independence claim
requires a separately provisioned grader and rejects self-grading/fallback; the
grader artifact records provider, model, profile, evidence class and isolation; and
all conclusions stay within evidence.

## Evidence and completion

Record manifests, randomized schedule, grader provenance/isolation and hostile
self-grading rejection, comparison artifacts, resource telemetry, uncertainty,
hostile report/privacy tests, full gates, immutable review, exact-head CI and
post-merge evidence.
