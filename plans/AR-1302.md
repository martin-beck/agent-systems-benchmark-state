# AR-1302: Provision a portable TLC CI/VM runner

## Outcome

Provide a clean, reproducible runner for the state repository's portable TLC admission tier.
The runner must supply the required portable containment mode, bounded process/thread admission,
adequate memory and swap, and isolated queues/locks without touching unrelated host workloads.

## Dependencies and ownership

This is state-repository infrastructure for blocked AR-1293 and has no product or asb-tui source
dependency. Own only runner definitions, immutable image/VM metadata, launch helpers, offline
fixtures and sanitized qualification evidence under `/srv/data/projects`. Do not edit handoffctl,
ASB product code, or the external root-owned TLC lock. Native ARM64 is not required; use a pinned
x86_64 container or VM and retain emulated portability labels where applicable.

Branch: `feature/ar-1302-portable-tlc-runner`; worktree:
`agent-systems-benchmark-state-ar-1302-portable-tlc-runner`.

## Work sequence

1. Establish a clean state worktree from protected `main` and read AR-1293, formal runner policy,
   and development documentation.
2. Select or build a digest-pinned container/VM image entirely under `/srv/data/projects`; record
   image/source/toolchain provenance, architecture, JVM/TLC versions, cgroup mode, CPU/thread,
   memory and swap limits, and all cache/artifact paths.
3. Implement a bounded launch helper that creates owner-private queue/lock/evidence paths, denies
   network and host mounts, fails closed on missing containment or insufficient capacity, and never
   changes unrelated host services or root-owned locks.
4. Run AR-1293 `portable-smoke` and required `pr-publication`/`full-exhaustive` tiers through the
   runner, including positive model execution and negative admission/containment tests. Repeat
   the portable tier enough to detect capacity flakiness and record sanitized terminal evidence.
5. Independently review the exact diff and all provenance/privacy/signature/DCO/quality gates.
   Publish only from a clean exact tree; merge and post-merge verify only after required CI is green.
   Update AR-1293 with the runner identity and results, then release this AR with durable evidence.

## Acceptance and evidence

Completion requires a reusable clean runner that passes portable attestation under
`TLC_CGROUP_MODE=portable`, avoids the host `EAGAIN`/swap failure, and runs the AR-1293 tiers with
owner-private bounded evidence. Host-only probes, unpinned images, disabled attestation, relaxed
resource limits, or native ARM64-only evidence do not qualify.
