# AR-1285: Runtime-owned strict-replay launch factory

## Outcome

Supply the runtime-issued authority boundary required by the real ASB primary strict-replay CLI,
without claiming the later cassette lifecycle or touching asb-tui.

## Dependencies and ownership

Dependencies: AR-1282, AR-1237, AR-1238, AR-1239. AR-1284 is blocked evidence and is not reused as
an implementation dependency. Owned paths: `crates/asb-runtime`, `crates/asb-replay`, `crates/asb-cli`,
and focused integration fixtures/tests for the launch-factory boundary. Branch:
`feature/ar-1285-runtime-launch-factory`; worktree:
`agent-systems-benchmark-ar-1285-runtime-launch-factory`.

## Work sequence

1. Read the complete ASB development documentation and this plan. Establish a clean worktree from
   protected main containing merged AR-1282.
2. Design an opaque runtime-issued context carrying validated launch input, resource lease, and
   immutable supervisor/sidecar identities. Keep issuance unavailable to ordinary CLI callers.
3. Bind the primary strict-replay argument path to consumption of that context; reject forged,
   stale, malformed, mismatched, or caller-constructed values before child creation.
4. Add bounded positive and negative tests, then run focused and full locked gates, independent
   exact-head review, signed/DCO publication, hosted CI, protected merge, and exact-main verification.

## Boundaries

This AR establishes authority issuance/consumption only. It must not invent a supervised lifecycle,
provider/descendant egress proof, cancellation/restart cleanup, or cassette callback semantics. Split
those remaining capabilities into a successor if they are not already available.
