# AR-0105: Repair sandbox test target portability

## Outcome

Make sandbox lease tests independent of repository-local build artifacts and existing parent directories.

## Dependencies and ownership

Dependencies: AR-0103.
Owned paths: `crates/asb-runtime/src/sandbox.rs` sandbox test fixtures only.
Branch: `fix/sandbox-test-portability`. Worktree: `agent-systems-benchmark-sandbox-test-portability`.
One worker owns this task; no Cargo workspace, lockfile, schema, or production behavior edits are allowed.

## Work sequence

1. Reproduce `leases_exclude_benchmark_and_ci_overlap` from an exact clean main tree with a fresh, nonexistent external `CARGO_TARGET_DIR`.
2. Replace repository-target assumptions with a collision-safe temporary fixture whose complete parent chain is created and cleaned by the test.
3. Add a focused negative regression proving no repository `target` directory or retained fixture is required.
4. Run the focused test repeatedly and all applicable workspace, lint, format, coverage, privacy, and provenance gates on the exact tree.
5. Publish a focused signed-DCO commit for immutable review and exact-head CI, integrate only after approval, then rerun the failing AR-0204 gate.

## Acceptance criteria

The original test passes at least three times with a fresh external target located under
`/srv/data/projects`; the repository-local `target` path is absent before and after the test;
parallel test processes cannot collide; failure cleanup leaves no lease or fixture residue; and
the full workspace suite passes from an exact clean tree without setup that masks the defect.

## Evidence and completion

Record exact source/head, external target paths, commands by digest, immutable commit, review,
CI, and post-merge outcomes. Include the original `ENOENT` as the regression basis and verify
x86_64 plus applicable aarch64 hosted checks. Exclude private paths outside `/srv/data/projects`,
