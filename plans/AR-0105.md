# AR-0105: Repair sandbox test target portability

## Outcome

Make sandbox lease tests independent of repository-local build artifacts and existing parent directories.

## Dependencies and ownership

Dependencies: AR-0103.
Owned paths: sandbox test fixtures only in `crates/asb-runtime/src/sandbox.rs` and
`crates/asb-runtime/tests/sandbox_boundary.rs`.
Branch: `fix/sandbox-test-portability`. Worktree: `agent-systems-benchmark-sandbox-test-portability`.
One worker owns this task; no Cargo workspace, lockfile, schema, or production behavior edits are allowed.

## Work sequence

1. Reproduce `leases_exclude_benchmark_and_ci_overlap` from an exact clean main tree with a fresh, nonexistent external `CARGO_TARGET_DIR`.
2. Reproduce the order-dependent `host_sentinel_is_removed_during_panic_unwind` integration failure where `target_root()` assumes another test has already created the repository target parent.
3. Replace every owned repository-target assumption with collision-safe temporary fixtures whose complete parent chains are created and cleaned by each test.
4. Add focused negative regressions proving no repository `target` directory, prior test ordering, or retained fixture is required.
5. Run the focused tests repeatedly in randomized/reversed/parallel order and all applicable workspace, lint, format, coverage, privacy, and provenance gates on the exact tree.
6. Publish a focused signed-DCO commit for immutable review and exact-head CI, integrate only after approval, then rerun the failing AR-0204 gate.

## Acceptance criteria

The original tests pass at least three times with distinct fresh external targets located under
`/srv/data/projects`; the repository-local `target` path is absent before and after every test;
unit and integration fixtures pass independently, in reversed/randomized order, and in parallel;
parallel test processes cannot collide; failure cleanup leaves no lease or fixture residue; and
the full workspace suite passes from an exact clean tree without setup that masks the defect.
