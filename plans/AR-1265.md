# AR-1265: Runtime-owned strict-replay CLI entrypoint

## Outcome

Replace the metadata-only strict-replay CLI path with a runtime-owned entrypoint that issues an
opaque launch authority, supervises the cassette process, denies provider/descendant egress, and
proves cancellation, restart, timeout/crash cleanup, and no-fallback behavior.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. The blocked AR-1262 branch is incident evidence only; do
not consume its unmerged code. Owned paths are the ASB runtime/CLI replay entrypoint, schemas,
fixtures, tests, and generated contract documentation. Branch:
`feature/ar-1265-runtime-owned-replay-entrypoint`. Worktree:
`agent-systems-benchmark-ar-1265-runtime-replay-entrypoint`.

## Work sequence

1. Read the complete product development docs and AR-1262 review evidence. Design a narrow
   authenticated runtime-to-CLI context boundary; callers cannot provide readiness, endpoint,
   command identities, or authority digests.
2. Implement runtime-issued opaque launch context consumed exactly once by the CLI. The actual
   replay-plan command must invoke supervised runtime dispatch, not merely emit metadata.
3. Add real credential-free cassette request/response fixtures, provider and descendant egress
   denial, cancellation/restart, timeout/crash reaping, stale/duplicate rejection, and strict
   no-live-fallback tests. Keep all commands bounded and offline after install.
4. Run focused repeats and full locked workspace gates, signatures/DCO/privacy/schema checks, then
   obtain independent exact-head review, publish a clean PR, wait for all exact-head CI, merge only
   after green checks, and verify all exact-main post-merge workflows.

## Acceptance criteria

No CLI path fabricates runtime authority or claims readiness. A real runtime-owned supervised
   replay succeeds with the approved cassette and fails closed on egress, stale/duplicate,
   cancellation, timeout/crash, malformed authority, or provider fallback. Exact provenance,
   clean-tree, signature/DCO, CI, review, and post-merge evidence are durable.
