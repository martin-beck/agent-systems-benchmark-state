# AR-1301: Supervised replay lifecycle fault matrix

## Outcome

Provide executable, end-to-end qualification of the strict-replay cassette lifecycle through the
runtime-owned dispatcher, supervised child, authenticated cassette service and approved delegated
namespace runner.

## Dependencies and ownership

Dependencies: AR-1300 (real runtime-to-replay cassette request/response path) and AR-1287
(approved signed Bubblewrap/systemd delegated runner). AR-1286 remains blocked historical lifecycle
evidence and is not an implementation branch. Own ASB lifecycle runner integration, deterministic
credential-free fixtures/tests, and relevant ASB schemas/docs only; no asb-tui or coordinator source.
Branch: `feature/ar-1301-replay-lifecycle-fault-matrix`; worktree:
`agent-systems-benchmark-ar-1301-replay-lifecycle-fault-matrix`.

## Work sequence

1. Verify protected-main ancestry, clean isolation, AR-1300 request/response behavior and AR-1287
   runner identity/capability attestations before promotion.
2. Execute a bounded positive cassette request/response case through the actual supervised child.
3. Add deterministic fault fixtures for provider/descendant egress denial, timeout, cancellation,
   crash, restart, socket/relay cleanup and reaping, unrelated-process non-interference, and
   strict no-fallback. Assert terminal status, bounded cleanup and absence of leaked descendants.
4. Run the complete matrix repeatedly enough to expose timing flakes, plus all focused/full locked
   ASB quality, policy, privacy, formal and platform gates. Record only sanitized evidence.
5. Obtain independent exact-head review, publish signed/DCO commits, merge via protected workflow,
   and verify exact-main post-merge workflows and coordinator reconciliation.

## Acceptance and evidence

The matrix is complete only when every case is executed—not ignored—against the real runtime-owned
path on the approved runner, with authenticated cassette response parity, denied provider/descendant
egress, terminal fault classification and cleanup evidence. Compilation, host-only probes,
transport-only tests, unqualified mocks or manually asserted logs are insufficient.
