# AR-0851: Adopt the shared workflow coordinator

## Scope

Adopt the public `martin-beck/agent-workflow-coordinator` release in Agent Systems Benchmark
State as a pinned, checksummed, self-contained vendored runtime. Keep ASB-specific identity,
worktree validation, status presentation, signing, and generated-view policy in an explicit
project integration boundary.

## Acceptance

- Vendor the exact reviewed upstream release without a runtime network or package dependency.
- Record upstream repository, version, commit, artifact hashes, and licensing in a lock manifest.
- Preserve ASB task transitions, revisions, leases, locking, timeouts, reconciliation,
  `STATUS.md`, command recording, signed+DCO commits, and replication behavior.
- Verify the vendor manifest locally and in path-filtered CI.
- Run upstream conformance fixtures plus ASB fault, race, renderer, schema, and live checks.
- Publish through a reviewed pull request with exact-head and post-merge green evidence.

## Isolation

Do not change benchmark product code, active task records, leases, generated views except through
handoffctl, or unrelated CI. Recover ambiguous publication by inspecting durable refs, commits,
checksums, and CI before retrying.
