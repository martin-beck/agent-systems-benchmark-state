# AR-0804: Build the terminal settings wizard

## Outcome

Deliver a separate `asb-tui` program that interactively builds and validates a complete run plan through the frontend API.

## Dependencies and ownership

Dependencies: AR-0313, AR-0314, AR-0803.
Owned paths: standalone TUI executable, navigation/state model, settings forms, previews, help, and UI tests.
Branch: `feature/tui-settings-wizard`. Worktree: `agent-systems-benchmark-tui-settings-wizard`.

## Work sequence

1. Guide selection of agents, shared/per-agent provider profiles, live or matching replay source, workloads, repetitions, concurrency, budgets, platforms, metrics, and result location.
2. Show defaults, effective values, unsupported combinations, consequences, and validation errors before launch.
3. Support keyboard-first navigation, contextual shortcut help, command/search palette, searchable selectors, backtracking without loss, reset, import/export, dry-run, and final plan review; mouse is optional rather than required.
4. Keep credentials in external secret references and redact sensitive fields from widgets, errors, snapshots, and crash reports.
5. Test small/large terminals, resize, color/no-color, Unicode/non-Unicode, screen readers/plain mode, interrupted input, reconnect, and malformed server data.

## Acceptance criteria

New users can produce a valid plan without memorizing flags; experts can inspect/import the exact manifest and operate efficiently from the keyboard; destructive/cost-bearing actions use consistent explicit confirmation; no run launches from the wizard until confirmation; noninteractive CLI behavior is unchanged; frontend crashes cannot affect the runner; and every displayed support/default claim comes from negotiated capabilities rather than hardcoded optimism.

## Evidence and completion

Record interaction fixtures, screenshots or text snapshots free of private data, accessibility tests, immutable commits, independent review, CI, and supported terminal/platform limits.
