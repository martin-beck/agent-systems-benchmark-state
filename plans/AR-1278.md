# AR-1278: Primary replay runtime client handoff

## Outcome

Make the real argument-level strict-replay command receive an authenticated runtime-issued replay
client and execute through the supervised transport boundary.

## Dependencies and ownership

Dependencies: AR-1237, AR-1238, AR-1239. AR-1275, AR-1276, and AR-1277 are blocked design evidence
only; their branches are not inputs. Owned paths: primary ASB CLI argument dispatch, runtime launch
handoff, cassette fixtures, and executable lifecycle tests. Branch:
`feature/ar-1278-primary-runtime-client`; worktree:
`agent-systems-benchmark-ar-1278-primary-runtime-client`.

## Acceptance

The command cannot execute without a runtime-issued client; it performs real supervised cassette
request/response traffic with provider and descendant egress denial, no live fallback,
cancellation/restart, timeout/crash reaping, cleanup, and malformed/stale/duplicate rejection.
Run full locked gates, independent review, exact-head CI, signed merge, and post-merge assurance.
