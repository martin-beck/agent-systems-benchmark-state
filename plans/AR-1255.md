# AR-1255: Bundle MockAgents transport and QEMU runner

## Outcome

Provide a reviewed runner bundle that executes the real MockAgents executable and Python transport
fixture in one pinned runtime, and runs the pinned arm64 artifact through an immutable QEMU-capable
image.

## Dependencies and ownership

Depends on AR-1254, AR-1253. Own only bundled fixture packaging, runner integration, and evidence;
do not modify asb-tui or weaken network/process gates.

## Acceptance

- One content-addressed read-only bundle contains the fixture and exact amd64/arm64 MockAgents
  artifacts; manifest closes source, version, architecture, image, QEMU and file digests.
- Real executable transport requests and responses are parsed in-container, including malformed,
  oversized, tool-result ordering, backpressure/cancellation, outbound connection denial, and
  process-tree cleanup with no residue.
- Arm64 executes under digest-pinned QEMU with repeat-clean-state evidence. Mutable images, host
  Python, extra mounts, ambient network, credentials, and unbounded output fail closed.
- Focused/full gates, signed DCO, independent review, exact-head CI, merge and post-merge checks pass.
