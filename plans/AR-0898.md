# AR-0898: Make ShellCheck fail closed

## Outcome

Install a reviewed digest-pinned ShellCheck on every supported CI architecture and prove that actionlint cannot silently omit delegated shell analysis.

## Dependencies and ownership

Dependencies: AR-0003, AR-0897, AR-1008.
Owned paths: quality-tool manifest and installer, workflow invocation, shell lint policy, negative fixtures, documentation, and provenance.
Branch: `fix/shellcheck-fail-closed`. Worktree: `agent-systems-benchmark-shellcheck-fail-closed`.

## Work sequence

1. Reuse the verified public Agent Workflow Quality ShellCheck 0.11.0 provenance and extraction design when its consumer contract and architecture coverage match; otherwise pin equivalent ASB-owned artifacts and digests explicitly.
2. Install only the reviewed executable, verify digest, executable type, exact version output and supported architecture, and fail before linting on any mismatch or missing tool.
3. Invoke actionlint with an explicit absolute `-shellcheck` path and independently assert the delegated tool is available; do not rely on actionlint's missing-tool behavior.
4. Add an otherwise valid workflow containing only a ShellCheck-detectable defect such as SC2086, plus missing, corrupt, wrong-version and permissive-tool fixtures.
5. Update quality documentation and run actionlint, direct ShellCheck, repository policy, privacy, supply-chain, x86_64 and aarch64 gates.

## Acceptance criteria

ShellCheck is content-pinned and installed on every claimed architecture; its absence or version drift fails CI; the negative suite fails if delegated shell analysis stops running; current clean workflows pass; and documentation no longer claims fail-closed behavior without executable evidence.

## Upstream boundary

Agent Workflow Quality already provides checksum-pinned ShellCheck and fail-closed adapter-tool handling. Do not open a duplicate upstream defect; escalate only a newly proven reusable-installer or architecture-contract gap with a minimal reproduction.

## Evidence and completion

Record source/release/license provenance, artifact digests, exact version output, negative-fixture outcomes, immutable review, exact-head CI, post-merge CI, and issue closure linkage.
