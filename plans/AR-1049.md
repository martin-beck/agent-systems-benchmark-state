# AR-1049: Bind tmux setup to the created window identity

## Outcome

Restore trusted-main terminal qualification by removing every assumption about tmux window indexes.
Acquire the exact immutable window identity from each successful session creation, validate it
strictly, and use it for the window-scoped remain-on-exit option.

## Scope and ownership

Repository: martin-beck/asb-tui only. Owned path: tmux qualification helpers and tests in
tests/terminal_foundation.rs. Branch: fix/tmux-created-window-identity. Worktree:
agent-systems-benchmark-asb-tui-tmux-created-window-identity. No renderer, application, lifecycle
protocol, dependency, release, workflow, or ASB source change is permitted.

## Failure evidence

Trusted-main run 34555068496 at exact merge 6853d319469ad28ee9ff8b115b7c4c79da1ab777
passed 18 of 22 terminal tests but all four tmux integration fixtures rejected
set-window-option -t session:0 remain-on-exit on. Repository quality run 34555068475 passed. This
falsifies the fixed first-window-index assumption while leaving the AR-1044 authority repair intact.

## Trust and parsing invariants

1. Each new-session command uses bounded output with -P -F '#{window_id}'. Accept exactly one line
   containing @ followed by one or more ASCII decimal digits and one final newline. Reject
   whitespace, signs, empty IDs, duplicate lines, non-UTF-8, oversized output and overflow. The
   exact immutable object identity @0 is valid and must not be confused with a fixed window index.
2. Construct the cleanup guard immediately after creation succeeds and before parsing the identity,
   setting options, or acquiring server/pane metadata. Malformed identity must still tear down only
   the exact private server and must never widen process signalling.
3. Configure remain-on-exit only through set-window-option -t @ID remain-on-exit on. Never derive a
   target from base-index, session defaults, ambient config, or caller text.
4. Expose only closed failure categories: creation_failed, malformed_window_identity,
   server_or_session_disappeared, and option_unsupported_or_unknown. Do not expose raw tmux output,
   paths, names, environment values, or arbitrary status text.
5. Preserve all retained server PID/start-time/socket identity, pane PID/TTY/foreground group,
   pre-TERM/pre-KILL revalidation, exact-server shutdown, stale-unconnectable socket and disposable
   private-root invariants from AR-1044.

## Work sequence and adversarial coverage

3. Convert all four live fixtures. Prove guard construction precedes parse/option failure and every

4. Run repeated focused/full terminal suites with exact-process leak checks, then all applicable

5. Freeze signed+DCO, obtain immutable different-agent review and exact-head CI, then await merge
   authorization. Require reviewed-tree integration and both post-merge workflows, especially
   trusted-main, before this recovery or AR-1048/1044/1042/1010 can be accepted.

## Acceptance

No tmux option setup assumes an index. Every live fixture acquires and strictly validates the
created window ID before targeting it; malformed identity and setup failure remain closed, bounded,
sanitized and cleanup-safe; repeated/full tests leak no owned process; and exact-head plus
trusted-main pass. The diff is test-only, signed, DCO-compliant and independently reviewed.
