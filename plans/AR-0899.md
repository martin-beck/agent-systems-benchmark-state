# AR-0899: Align and harden Gitleaks execution

## Outcome

Make local and CI secret scans use one deterministic revision-scoped command and prevent unreviewed broadening of the Gitleaks configuration from silently weakening the gate.

## Dependencies and ownership

Dependencies: AR-0003, AR-0898.
Owned paths: Gitleaks execution wrapper, quality workflow, `.gitleaks.toml` policy, repository-policy checks, negative fixtures, and quality documentation.
Branch: `fix/gitleaks-revision-config-integrity`. Worktree: `agent-systems-benchmark-gitleaks-revision-config-integrity`.

## Work sequence

1. Add one fail-closed wrapper used by CI and documented local checks; require explicit base/head or one exact head and pass the resulting `--log-opts` plus an explicit validated config path.
2. Match pull-request, push, initial-history and local `origin/main..HEAD` semantics without scanning unrelated refs or accepting an empty/ambiguous range.
3. Add repositories with a secret only on an unrelated branch and only in the introduced range; prove the former passes and the latter fails with redacted output.
4. Validate the exact narrow `.gitleaks.toml` structure and allowlist entries in repository policy; reject broad paths, regexes, global rule suppression, unknown keys, config replacement and config/tool revision mismatch.
5. Document configuration ownership, approved allowlist review, false-positive handling, reproduction commands, and the distinction between a content digest and a credential.

## Acceptance criteria

The documented local command and CI invoke the same wrapper; identical base/head/config inputs produce identical verdicts regardless of other refs; introduced secrets fail; unrelated branches do not; broad configuration weakening fails before scanning; findings remain redacted; and the existing tokenizer-digest exception remains exact and tested.

## Upstream boundary

This is an ASB wrapper, documentation and repository-policy defect. Escalate to Gitleaks or Agent Workflow Quality only if a minimized reproduction proves their pinned upstream behavior violates its documented contract.

## Evidence and completion

Record scoped/unscoped commit counts, fixture results, validated config digest, privacy review, immutable commit, exact-head CI, post-merge CI, and issue closure linkage.
