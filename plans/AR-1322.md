# AR-1322 authenticated agent release-index source

## Outcome

Provide ASB with a bounded, locally pinned, cryptographically authenticated
release-index source that can promote only complete agent package closures.

## Scope

- signed envelope schema and explicit offline trust-root configuration;
- bounded file topology, size, freshness, target and generation checks;
- package, detached-signature, source, SBOM, license and capability closure
  validation using existing `AgentCatalog` types;
- atomic promotion into AR-1320 persistence;
- hostile mutation, rollback, duplicate, stale and restart tests;
- exact ASB-to-asb-tui catalog evidence.

## Acceptance

- unsigned, tampered, duplicate, stale, partial and wrong-target indexes fail
  closed;
- a complete verified fixture becomes selectable after restart and refresh;
- incomplete entries remain explanatory but unavailable;
- locked tests, clippy, schema, DCO, hosted exact-head and post-merge live
  control evidence pass.
