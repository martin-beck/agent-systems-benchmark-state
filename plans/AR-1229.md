# AR-1229: Integrate provider authentication into ASB application surfaces

## Outcome

Persist credential-free enrollment metadata in `asb-config`, expose authenticated renderer-neutral
enrollment/status/rotate/revoke requests through `asb-control`, and provide bounded `asb auth`
commands. Secret input is accepted only through one-shot terminal, descriptor or pinned-helper
channels; no key enters argv, ordinary environment, config, control frames, logs or evidence.

## Dependencies and ownership

Dependencies: AR-1228 and AR-1230. Repository: `martin-beck/agent-systems-benchmark`.
Owned paths: config enrollment registry and schema, control request/response variants, CLI dispatch,
durable atomic persistence, integration fixtures and negative/privacy tests. Branch:
`feature/ar-1229-auth-application-integration`. Worktree:
`agent-systems-benchmark-ar-1229-auth-application-integration`.

## Acceptance and evidence

Registry records are bounded, versioned, unknown-field rejecting and contain only reference digests,
source, connection identity, generation and public status. Control authorization and idempotency
bind every mutation. Rotation and revoke survive crash/restart and partial backend failure. Run
focused/full Rust quality, control, privacy, fault and recovery gates, independent exact-head review,
exact-head CI and post-merge verification.
