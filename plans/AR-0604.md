# AR-0604: Qualify native CSB monitoring contention and overhead

## Outcome

Produce independent native evidence identifying exactly which pinned CSB signals may be mapped
into ASB and which combinations remain unsupported; this task qualifies evidence and does not own
the production mapping bridge.

## Dependencies and ownership

Dependencies: AR-0201, AR-0202, AR-0601.
Owned paths: a new asb-csb-qualification harness, native monitoring fixtures, a machine-readable
CSB monitoring support matrix, and docs/CSB_MONITORING_QUALIFICATION.md. Root Cargo/schema/release
edits are coordinator-serialized. Do not edit the production asb-csb mapping owned by AR-0602.
Branch: feature/csb-native-qualification. Worktree:
agent-systems-benchmark-csb-native-qualification.

## Work sequence

1. Enumerate every accepted and rejected CSB signal with immutable CSB/ASB provenance, typed metric
   ID, value type, unit, aggregation, host/cgroup/process/thread scope, clock, timestamp/window,
   resolution, privilege/capability state, availability reason, and measured sampling loss.
2. Validate finite numeric bounds, counter/gauge semantics, reset/wrap/overflow behavior, clock
   regression and late-window rules, descriptor collisions, bounded incremental decoding, and
   exclusive ownership when native and CSB collectors coexist.
3. Run randomized counterbalanced repeated-seed monitor-off, ASB-native, and CSB-monitor A/B trials
   with independent oracles for CPU saturation, memory pressure/OOM, buffered/direct block I/O,
   scheduler run queue, lock/futex contention, and cancellation.
4. Distinguish utilization, PSI, and throttling from causal scheduler or lock contention. Record
   PMU time-enabled/time-running multiplex scaling, BPF attach/BTF/privilege and lost-event
   evidence, attribution contamination, and complete teardown.
5. Publish idle/load collector overhead, workload latency/quality perturbation, uncertainty,
   acceptance thresholds, and a native x86_64/aarch64 mainstream-Linux/openEuler matrix. An
   unprovisioned or failed cell is unsupported, never inferred from cross-build or emulation.

## Acceptance criteria

- Hand-calculated fixtures and negative tests prove the exact raw-to-typed mapping, units, clocks,
  windows, loss accounting, unavailable states, duplicate ownership rejection, and privacy bounds.
- Controlled positive and no-contention/confounder cases causally separate resource use and
  pressure from scheduler, lock, or futex evidence; mere counter movement is never sufficient.
- PMU multiplexing, BPF loss/attach/teardown, missing permission/BTF/cgroup, collector crash/hang,
  partial/malformed output, attribution mismatch, cancellation, and coordinator-crash cleanup all
  fail closed or remain explicitly unavailable.
- Counterbalanced native results publish bounded overhead/loss and uncertainty for every supported
  distro/architecture/kernel combination. Missing capabilities and all untested combinations are
  listed as unsupported.

## Evidence and completion

Record immutable revisions, artifacts, licenses, kernels and capability manifests, native runner
identity, exact fixture/oracle definitions, raw-to-normalized checks, repeated A/B results,
overhead/loss bounds, residual collectors/scopes audit, privacy review, immutable review,
exact-head CI, and post-merge verification. Retain only bounded redacted public evidence.
